# OpenCompare v0.2.26 发布说明

[English](https://github.com/chaxiu/OpenCompare/blob/v0.2.26/docs/release-notes/v0.2.26.md) | 简体中文

v0.2.26 是维护版，唯一的用户可见改动在首页：最近对比列表最多展示 5 条，超过时用「全部 N」按钮打开弹窗查看历史里保存的全部条目（上限 20 条），空态引导收成一句。比较语义、IPC、导出与快照格式均未改动。

## 本次变化

### 最近对比最多 5 条

首页只保留最新的 5 条最近对比。历史里超过 5 条时，「清空历史」旁出现「全部 N」按钮，N 为已保存的条目数；不足 5 条时不出现该按钮。列表仍按最新在前排序，在短列表里重新打开或删除某一行的行为与之前一致。

### 「全部 N」弹窗

「全部 N」按钮打开标题为「全部 N 条最近对比」的弹窗，列出历史中保存的全部条目，而历史上限是 20 条。弹窗内逐行重新打开与删除照常可用，关闭后焦点回到打开它的按钮，键盘操作不离开首页。

### 空态引导收成一句

空态说明改为一句「拖入左右两侧的文件或文件夹，或点「新建对比」手动填路径」，不再用整段文字罗列各种入口；内置示例的说明保持不变。

### 发布工程改动

本范围其余改动对用户不可见。版本语义单点收敛到一处：`package.json#version`、CHANGELOG 顶部段、双语发布说明与 `release.yml` 的 `workflow_dispatch` 默认 tag 一并指向 v0.2.26；README 第 5 行在 tag 发布前仍指向已公开的 v0.2.25。另有提交重钉截图取证、抬高空态首页覆盖所需的仓库测试行数天花板、以及把 shell 信号退出归类为可重试环境失败；这些都不改变任何对比结果。

## Windows 安装包与免安装 zip

Windows 与上一版保持相同的打包口径；免安装 zip 的说明见下。

### Windows 免安装包

Windows 同时提供 NSIS 安装包与免安装 `.zip`，解压后直接运行、无安装步骤。自动更新仍只指向 NSIS 安装包，所以免安装 zip 只是下载形态。

## macOS 签名与公证

macOS 构建继续使用 Developer ID 签名与 Apple 公证；签名凭据缺失时 CI 仍 fail-closed。本版不改变这一口径。

## 不做的事

- 「忽略空白差异」开关仍默认关闭；打开时也只吞空格与制表符，高亮与差异计数读取同一份比较结果，而状态栏仍显示原始值。
- 重载仍在原会话读取当前文件对，不新建会话，滚动位置与开关状态保持不变；某一侧读不到时保留上一次结果。
- 交换仍只对调内容、指示条与计数以及状态栏原始值，再次交换即可复原。
- 工作簿对比沿用 v0.2.25 口径：`.xlsx` / `.xlsm` 仍按四态表格比较，一律不求值公式，SheetJS 解析层未改动，超限容器仍以 `XLSX_LIMIT_EXCEEDED` 拒绝（含 zip bomb）。出厂 renderer 仍不依赖 `Buffer` / `process` 全局解析工作簿；二次启动仍先剥掉应用入口再接管。
- 导出与快照格式、目录扫描口径与发布通道不变。

## 风险与验证规模

相对 v0.2.25，本版唯一新用户面是首页：5 条上限、「全部 N」弹窗与单句空态。验证覆盖上限本身、历史存满 20 条时的弹窗、两种语言的空态文案，以及 package 版本 / CHANGELOG / 双语说明 / workflow 默认 tag 四处版本锚点。文本、代码、目录、CSV 与工作簿家族的比较语义、IPC、导出与快照格式均未触碰。本版不声称任何性能或内存数字。

## 升级方式

建议从 v0.2.25 升级。按平台替换为 v0.2.26 安装包（macOS `.dmg` / `.zip`、Windows 安装包、Linux `.AppImage` / `.deb`）。Windows 既可装 NSIS `.exe`，也可下载 `OpenCompare-0.2.26-win-x64.zip` 解压即用；自动更新仍只用 NSIS `.exe`。本次不变更数据格式，已有会话与设置照常可用。
