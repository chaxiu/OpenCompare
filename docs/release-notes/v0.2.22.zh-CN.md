# OpenCompare v0.2.22 发布说明

[English](https://github.com/chaxiu/OpenCompare/blob/v0.2.22/docs/release-notes/v0.2.22.md) | 简体中文

v0.2.22 收敛已合入主干、用户可见的改动：扩展名无法识别的文件改按内容判定打开，README 截图补齐中英两套。除这些改动外，比较语义、IPC、导出与快照格式都没有改动。

## 本次变化

### 未知扩展名按内容判定

扩展名无法识别时，打开链路对每一侧只读取一次原始字节，据此判定文本或二进制。文本按代码家族打开，UTF-8 / GBK 编码与换行事实与其他文本文件一致；二进制在打开链路被拒绝，提示写明是哪一侧的哪个文件，并说明「扩展名无法识别时按内容判断，二进制文件不支持」。

同一判定在四个打开入口保持一致：手动路径与 argv / `opencompare://`、拖放 / 选择器 / 历史重开、目录树双击，以及三向合并。已知扩展名的行为与读取次数不变，不新增探测；未知扩展名每侧恰好读取一次，正文、编码、换行与字节事实都来自这一次读取。

### 双语 README 截图

README 现有四张截图：工作台与文件对比各一张，中英各一套。四张图都取自真实构建的应用与真实临时目录，语言由持久化设置文件钉住，而不是宿主 locale。`docs/screenshots.md` 的 captured commit、字节数与 sha256 provenance 已按该次取证重钉。

## Windows 安装包与免安装 zip

Windows 的打包口径与上一版一致；免安装下载说明见下节。

### Windows 免安装包

Windows 同时提供 NSIS 安装包与免安装 `.zip`，解压即用、无安装步骤。自动更新仍指向 NSIS 安装包，免安装 zip 只作为下载。

## macOS 签名与公证

macOS 包保持 Developer ID 签名与 Apple 公证，签名凭据缺失时 CI fail-closed。本版不改这一口径。

## 不做的事

- 「忽略空白差异」开关仍默认关闭；开启时只吞空格与制表符，行级高亮、行内高亮与差异计数仍读取同一份比较结果，状态栏仍显示原始值。
- 重载仍在原会话读取当前文件对，不新建会话，滚动位置与开关状态保持不变；某一侧读取失败时保留上一次结果。
- 交换仍只对调内容、状态栏原始值、指示条与计数，再次交换即可复原。
- 不改导出与快照格式、目录扫描口径与发布通道；除上述内容兜底外，比较语义保持原状。
- 本范围内的 CI、覆盖率、测试、截图取证与 ratchet 调整属于验证面，不写成用户功能。

## 风险与验证规模

v0.2.22 相对 v0.2.21 的新增部分是内容兜底判定与截图资产。比较语义、IPC、导出与快照格式均未改动。验证覆盖内容家族判定与读取预算、四个打开入口，以及双语说明与截图 provenance，均通过仓库门禁。本文件不写任何性能或内存数字。

## 升级方式

建议从 v0.2.21 升级：下载 v0.2.22 对应平台的新安装包覆盖安装（macOS `.dmg` / `.zip`，Windows 安装包，Linux `.AppImage` / `.deb`）。Windows 可选 NSIS 安装包，或下载 `OpenCompare-0.2.22-win-x64.zip` 解压即用；自动更新仍只走 NSIS exe。本次不需要迁移数据，已有的会话与设置照常可用。
