# OpenCompare v0.2.19 release notes

English | [简体中文](https://github.com/chaxiu/OpenCompare/blob/v0.2.19/docs/release-notes/v0.2.19.zh-CN.md)

v0.2.19 converges three user-visible text-comparison actions already merged into main: an **ignore whitespace** switch that is off by default, an explicit reload of the current file pair, and an explicit swap of the left and right panes. Beyond these three changes, comparison semantics, IPC, export and snapshot formats are untouched.

## What changed

### Ignore whitespace differences

The **ignore whitespace** switch is off by default. When it is on, only spaces and tabs are swallowed for the comparison: line-level highlights, inline highlights and the difference count read one comparison result, while the panel text and the status bar still show the raw values. Turning the switch off restores a strict comparison.

### Reload the current file pair

Reload re-reads the current pair of files in the same session instead of opening a new one, so the scroll position and switches stay put. If a side cannot be read, the error is shown in place and the view keeps the previous result.

### Swap the left and right panes

Swapping puts the right side on the left and the left side on the right: content, raw values in the status bar, the ruler and counts are exchanged together. Swapping again restores the original order.

## Windows installer and portable zip

Windows keeps the same packaging contract as the previous release; see the portable download note below.

### Windows portable download

Windows ships both the NSIS installer and a portable `.zip` that runs right after extraction with no installation step. Auto-update keeps resolving to the NSIS installer, so the portable zip is a download only.

## macOS signing and notarization

The macOS build keeps Developer ID signing and Apple notarization, and CI fails closed when the signing credentials are missing. This release does not change that posture.

## Not in this release

- Beyond the three changes above, no comparison semantics or IPC are changed: four-state semantics, line diff results and three-way merge behavior stay as they are.
- No changes to export or snapshot formats, directory scanning or the release channel.
- CI and release-verification work in this range is validation plumbing, not a user feature.

## Risk and verification scope

The change is limited to the ignore-whitespace switch, the explicit reload and the explicit swap; comparison semantics, IPC, export and snapshot formats are untouched. Verification covers the text dual-pane switch path, the reload path and the swap path through the repository gates. This release states no performance or memory numbers.

## Upgrade

Upgrade from v0.2.18. Replace the app with the v0.2.19 package for your platform (macOS `.dmg` / `.zip`, Windows installer, Linux `.AppImage` / `.deb`). On Windows you can either install with the NSIS `.exe` or download `OpenCompare-0.2.19-win-x64.zip` and run it right after extracting; auto-update still only uses the NSIS `.exe`. No data migration is needed; existing sessions and settings keep working.
