# OpenCompare v0.2.24 发布说明

[English](https://github.com/chaxiu/OpenCompare/blob/v0.2.24/docs/release-notes/v0.2.24.md) | 简体中文

v0.2.24 是本次功能迭代的收口版本，收敛三项用户可见修复与两项覆盖率治理：窗口菜单栏与工具栏跟随应用主题、代码工具栏显式可见左右交换并给出同一动作的快捷键、上一处 / 下一处差异块垂直居中跳转；覆盖率门对 0 可执行语句模块显式豁免，发布点覆盖率基线独立重采样。除这些修复与治理外，比较语义、IPC、导出与快照格式都没有改动。

## 本次变化

### 菜单栏与工具栏跟随主题

窗口原生菜单栏与标题背板现在与应用内亮暗 / 跟随系统的解析结果同步，自绘工具栏 band 与主界面使用同一层级表面色。renderer 只推主题模式而非解析值，因此「跟随系统」仍由 OS 驱动；主进程用 Electron 原生主题能力落地，并在下次启动时恢复同一设置。macOS 的全局菜单栏由系统拥有、不接受应用着色，这是既定的平台差异。

### 工具栏显式交换与快捷键

代码 diff 工具栏现在直接显示「交换左右」，不再只藏在「更多」菜单里。工具栏按钮、菜单项与 `Cmd/Ctrl+Shift+S` 快捷键调用同一交换动作，再次交换即可复原；快捷键串、tooltip 与菜单文案来自同一份描述，不会各自漂移。

### 上一处 / 下一处居中跳转

上一处 / 下一处现在把目标差异块滚到视口垂直居中，并保留上下文行；差异块行首贴顶的旧行为不再出现。首块、末块、短文档、视口高度未知与块高于视口都确定性夹取在 `[0, maxScroll]`，左右两栏共用同一目标值。

### 0 可执行语句模块显式豁免

覆盖率门现在把 statements / lines / functions / branches 的可执行总数全为 0 的模块显式豁免：每个模块逐条打印 `0 可执行语句` 的依据，不再触发模块集合缺失或单模块分支地板。真实有可执行代码但覆盖为 0 的模块仍然判红，floors、ignore 指令与 exclude 范围保持不变。

### 发布点覆盖率重采样

发布点基线在 v0.2.23 之后以一次真实 v8 冷跑重采样，刷新了 `.munk/baseline/coverage.json` 的采样提交与 totals。同一基线还做了门的正反实跑：positive 通过，negative floor 与 stale 按预期判红。这属于验证面治理，不写成新的用户功能。

## Windows 安装包与免安装 zip

Windows 的打包口径与上一版一致；免安装下载说明见下节。

### Windows 免安装包

Windows 同时提供 NSIS 安装包与免安装 `.zip`，解压即用、无安装步骤。自动更新仍指向 NSIS 安装包，免安装 zip 只作为下载。

## macOS 签名与公证

macOS 包保持 Developer ID 签名与 Apple 公证，签名凭据缺失时 CI fail-closed。本版不改这一口径。

## 不做的事

- 「忽略空白差异」开关仍默认关闭；开启时只吞空格与制表符，行级高亮、行内高亮与差异计数仍读取同一份比较结果，状态栏仍显示原始值。
- 重载仍在原会话读取当前文件对，不新建会话，滚动位置与开关状态保持不变；某一侧读取失败时保留上一次结果。
- 交换仍只对调内容、状态栏原始值、指示条与计数，再次交换即可复原。
- 不改导出与快照格式、目录扫描口径与发布通道，比较语义保持原状。
- 本范围内的 CI、覆盖率、测试、截图取证与 ratchet 调整属于验证面，不写成用户功能。

## 风险与验证规模

v0.2.24 相对 v0.2.23 的新增部分是原生窗口外壳与工具栏 band 的主题同步、显式交换入口与同源快捷键、上一处 / 下一处的居中跳转、0 可执行语句豁免与发布点重采样。比较语义、IPC、导出与快照格式均未改动。验证覆盖亮暗两套下的主题模式桥接与表面层级、三个交换入口共用同一动作、滚动夹取的各种边界、豁免的正反自测、重采样基线经发布门校验，以及双语说明与截图 provenance 通过仓库门禁。本文件不写任何性能或内存数字。

## 升级方式

建议从 v0.2.23 升级：下载 v0.2.24 对应平台的新安装包覆盖安装（macOS `.dmg` / `.zip`，Windows 安装包，Linux `.AppImage` / `.deb`）。Windows 可选 NSIS 安装包，或下载 `OpenCompare-0.2.24-win-x64.zip` 解压即用；自动更新仍只走 NSIS exe。本次不需要迁移数据，已有的会话与设置照常可用。
