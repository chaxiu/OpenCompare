# OpenCompare v0.2.8 发布说明

OpenCompare v0.2.8 带来两项面向用户的变化：目录对比结果可导出为自包含单文件 HTML 报告，对外品牌与入口更名为 Open Rebuilds。对比算法、目录扫描、快照格式与发布模型均未改动。

## 本次变化

### 目录对比结果导出为自包含单文件 HTML 报告

- **常驻导出入口**：目录视图工具栏提供「导出 HTML 报告」按钮，经系统保存框选择位置后落盘；取消保存不会写入文件。
- **单文件自包含**：产物内联 CSS，无 JS，无外链 CSS / 字体 / 图片，也不引用任何 http(s) 资源，用 `file://` 直接打开即可阅读，无需联网或安装其它软件。
- **路径隐私**：左右路径默认相对化到公共祖先，并默认开启「隐藏本机路径」开关，报告里只出现相对路径或目录名；报告顶部固定一行「由本机生成，分享前自查路径」。
- **上限与截断**：单份报告行数上限 200,000、字节上限 10 MB；发生截断时报告内写明「已展示 N / 原始 M（已截断）」，并提示完整清单请在本机查看。
- **统计与语言同源**：报告保留相同 / 新增 / 删除 / 修改四态计数与应用版本，取自与界面同一状态源；`<html lang>` 跟随当前界面语言，中英界面下读屏与翻译工具都能正确识别。

### 对外品牌与入口更名为 Open Rebuilds

- **入口更名**：README 两版的项目入口章节由原名统一更名为 Open Rebuilds，并链接 <https://github.com/munk-sh/open-rebuilds>；同构镜像与 9 节结构保持不变。
- **发布口径不变**：本次只改对外品牌与 README 入口链接。安装包品牌、`appId`、`productName`、快照格式与发布通道都不变，不是安装包改名。

## 升级方式

建议 v0.2.7 及更早的用户升级到 v0.2.8。本次升级不改变对比结果、快照格式与本地设置结构。

下载 v0.2.8 对应平台的新安装包覆盖安装即可：

- macOS：`.dmg` 或 `.zip`
- Windows：`OpenCompare-Setup-0.2.8.exe`
- Linux：`.AppImage` 或 `.deb`

macOS 安装包经 Developer ID 签名 + Apple 公证流程产出；签名与公证口径不变，凭据缺失时发版流程会直接失败（fail-closed），不会发布未签名裸包。
