# OpenCompare v0.2.10 发布说明

v0.2.10 只有一项面向用户的变化：双栏文本 / 代码对比的侧边新增一条常驻的竖向行级四态差异指示条。长文件的对比里，指示条用竖向分布标出差异大致落在整份文件的哪些位置，作为定位时的参照。对比与合并算法、目录扫描与快照格式都没有改动。

## 本次变化

### 双栏 diff 侧边常驻竖向四态差异指示条

- **四态聚合**：指示条按本次对比已经算出的行级 `same` / `added` / `removed` / `modified` 四态聚合，把有差异的行（新增 / 删除 / 修改）在窄条上按对应状态标出，相同行不着色。
- **常驻可见**：内置样本、目录下钻、拖放与打开文件进入的双栏对比都带这条指示条；切到三栏合并时不显示。
- **随滚动同步**：滚动任一栏时，指示条上的视口窗跟随移动，标出的差异位置与对应行号不变。
- **点选跳转（设计行为，大行数下未实测）**：按设计，点选指示条上的标记会选中对应的差异块，两栏同步滚动到该块首行，工具栏的差异计数与标记同步；指示条可聚焦，方向键在差异块之间循环，回车重新定位当前块。上述点选与键盘跳转只是本版的设计行为：在 350,000 行文本模型（源码拼接）这类大行数双栏对比上，点选指示条的命中范围、以及方向键与回车的跳转落点尚未实测，本文件不把它们写成已可用的能力。

## 不做的事

- 不做文本缩略图 / minimap 渲染：指示条只画状态标记与视口窗，不渲染任何行内文字或代码缩略。
- 不新增扫描或哈希：指示条复用本次对比已算出的行级差异结果，不额外读取文件、不重新扫描目录、不计算哈希。
- 不改对比与合并算法：四态语义、行级差异结果与三向合并行为保持原状。

## 风险与验证规模

本版改动只落在渲染层的指示条与跳转接线，不触碰对比 / 合并 / 扫描算法、文件读写通道与快照格式。

已实测的范围只有一项：在两侧各 350,000 行文本模型（源码拼接）的双栏对比上，可以打开双栏视图，且滚动任一栏时视口窗同步、标记位置不变。

未实测的范围另列，本文件不为它们写任何数值：同规模文本下的点选命中与键盘跳转是否可靠、目录对比在条目规模上的表现、以及长文件对比下指示条的内存占用，都还没有实机结论。

上述未实测项统一记为「L1 前待实机」：这些结论由 product-qa 场次产出，run id 待该场次回填，回填前本文件不写未实测的数值。

## 升级方式

建议从 v0.2.9 升级。下载 v0.2.10 对应平台的新安装包覆盖安装（macOS `.dmg` / `.zip`，Windows `OpenCompare-Setup-0.2.10.exe`，Linux `.AppImage` / `.deb`）。签名与公证口径不变：macOS 包经 Developer ID 签名 + Apple 公证，凭据缺失时 fail-closed。本次不需要迁移数据，已有的会话与设置照常可用。
