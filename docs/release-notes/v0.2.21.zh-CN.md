# OpenCompare v0.2.21 发布说明

[English](https://github.com/chaxiu/OpenCompare/blob/v0.2.21/docs/release-notes/v0.2.21.md) | 简体中文

v0.2.21 收敛已合入主干、用户可见的改动：并入 v0.2.20 已打 tag 但从未发出公开 Release 的对比历史与真实三向合并会话入口，并合入 UI 视觉打磨轮——顶部控件带收紧、目录工具行合成单行并在窄窗折叠、状态栏只保留当前场景度量、四态图例对比度达标、差异视图行距与指示条收紧，以及唯一设计 token 源与控件三件套。除这些会话与界面呈现改动外，比较语义、IPC、导出与快照格式都没有改动。

## 本次变化

### 对比历史

历史清单改为纯模型并经平台通道持久化，重启后最近记录仍在。新建页列出最近的对比，点击一次即可按原开关重开同一文件对、目录对或合并。重开前先做路径预检：坏路径就地提示，不建半棵树。失败条目以错误行保留，可逐条移除；清单上限 20 条混合记录，可显式清空。

### 三向合并会话

真实合并会话可从工作台与历史进入；重开合并时保持左右开关，重启应用后仍能恢复同一会话。

### 顶部控件带收紧

就绪态顶部控件带合计 120 逻辑像素：应用标题 32、会话标签 28、上下文工具行 36、面板头 24；状态栏单行高 24。

### 目录工具行与窄窗

目录工具行合成一行：过滤 segmented 控件、一个实心主操作、12px 间距加 1px 竖分隔，再是「更多」。快照导入与导出六项、导出 HTML、隐藏本机路径收进「更多」菜单或设置。

窄窗折叠阶梯固定：先折叠图例状态词，再折叠同步主按钮文案，最后行容器换行。单行 band 高 36，两行 band 高 72，不横向滚动裁切。

「更多」菜单在 800 高视口内完整可见；下方空间不足时向上翻转或按视口夹取，不靠内部滚动条藏条目。Escape 与点击外部关闭保持。

### 状态栏与差异图例

目录四态图例只保留在过滤行一处，状态栏不再重复。状态栏只保留当前场景的行或条目度量与编码换行事实；左右编码与换行相同时只写一次。

窄窗口下状态栏换到第二行而不裁切，单行高度为 24。

浅色主题下四态图例前景对 chip 背景的对比度均不低于 4.5:1，实测 4.78、4.66、4.60、4.62；暗色取值不变，为 6.41、6.47、5.16、6.51。

### 差异视图

代码行高 22，差异正文为 12px 等宽字体、行号对齐。右侧为 2px 指示条轨道，含当前视窗矩形、差异块与 hover 行号，并与竖向滚动条留出 6px。单词级差异改为 12% 柔底色加 1px 下划线，不再使用 40% 实底。

### 设计 token 与控件

`src/renderer/src/assets/main.css` 是唯一 token 源：字号 11、12、13、14、15，行高 16、18、20、24，间距以 0.25rem 为基数，即 4、8、12、16、24，圆角 4、6、8，控件高 28、32、36。亮色与暗色两套主题重定同名 token。

控件三件套为：三档强调的 Button、28×16 方形勾选、20px chip（8px 色点 + 文案 + 12% 语义底色），以及 30px tab 加 2px 品牌下划线。界面收敛到 4 个色相：蓝、绿、红、琥珀。conflict 复用 modified 色族并以虚线描边与文案区分，danger 与 removed 同色相。

### 文档与截图

README 两张截图在视觉基础与工具行模型变更后重出，`docs/screenshots.md` 的 captured commit、字节数与 sha256 provenance 重钉；v1 视觉 before/after 截图与测量文档随视觉轮入库。README 正文与版本指针不动。

## Windows 安装包与免安装 zip

Windows 的打包口径与上一版一致；免安装下载说明见下节。

### Windows 免安装包

Windows 同时提供 NSIS 安装包与免安装 `.zip`，解压即用、无安装步骤。自动更新仍指向 NSIS 安装包，免安装 zip 只作为下载。

## macOS 签名与公证

macOS 包保持 Developer ID 签名与 Apple 公证，签名凭据缺失时 CI fail-closed。本版不改这一口径。

## 不做的事

- 「忽略空白差异」开关仍默认关闭；开启时只吞空格与制表符，行级高亮、行内高亮与差异计数仍读取同一份比较结果，状态栏仍显示原始值。
- 重载仍在原会话读取当前文件对，不新建会话，滚动位置与开关状态保持不变；某一侧读取失败时保留上一次结果。
- 交换仍只对调内容、状态栏原始值、指示条与计数，再次交换即可复原。
- 不改导出与快照格式、目录扫描口径与发布通道；除上述界面呈现工作外，比较语义保持原状。
- 本范围内的 CI、覆盖率与基线文档提交属于验证面，不写成用户功能。

## 风险与验证规模

v0.2.21 相对 v0.2.20 的新增部分只调整界面呈现：顶部控件带、目录工具行 band、状态栏与差异图例、差异视图度量、唯一 token 源与截图；并入的对比历史与三向合并会话沿用 v0.2.20 已验证实现。比较语义、IPC、导出与快照格式均未改动。验证覆盖壳层布局模型、工具行折叠阶梯、状态栏度量、差异视图几何与 token 契约，均通过仓库门禁。本文件不写任何性能或内存数字。

## 升级方式

建议从 v0.2.19 升级：下载 v0.2.21 对应平台的新安装包覆盖安装（macOS `.dmg` / `.zip`，Windows 安装包，Linux `.AppImage` / `.deb`）。Windows 可选 NSIS 安装包，或下载 `OpenCompare-0.2.21-win-x64.zip` 解压即用；自动更新仍只走 NSIS exe。本次不需要迁移数据，已有的会话与设置照常可用。
