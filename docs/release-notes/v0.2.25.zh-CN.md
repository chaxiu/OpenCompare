# OpenCompare v0.2.25 发布说明

[English](https://github.com/chaxiu/OpenCompare/blob/v0.2.25/docs/release-notes/v0.2.25.md) | 简体中文

v0.2.25 新增 `.xlsx` / `.xlsm` 工作簿的表格对比，并修复 v0.2.24 之后发现的两个阻断：工作簿现在能在沙箱 renderer 的出厂构建里打开，二次启动带文件参数接管时不再把应用目录当成左路径。既有文本、代码、目录与 CSV 家族的比较语义、IPC、导出与快照格式均未改动。

## 本次变化

### 工作簿取值层

新增的纯函数层把 `.xlsx` / `.xlsm` 读成与 CSV 链路相同的 `{ header, rows, meta }` 形状，表格对齐无需二次转换。只读公式缓存值：不求值，无缓存值的单元格按空比较并把条数记进 `meta`；合并区只取左上锚点，样式与批注不参与差异，日期按工作簿自身的 1900 或 1904 基准归一化。隐藏行列默认参与比较并在 `meta` 标注，空表头回退为列字母，多张 sheet 按名大小写不敏感配对、左右独有 sheet 单列。随包的 SheetJS 0.20.3 tarball 以 sha256 钉版，绝不使用 npm 0.18.5 线。

### 解析上限与 zip bomb 拒绝

工作簿在解压任何内容之前先判：zip 中央目录校验容器体积、条目数、最大单条目、压缩比与累计解压预算，解压后远超存储体积的容器直接按 zip bomb 拒绝。sheet XML、共享字符串表与 sheet 边界各带上限，运行时水位在预算 60% 记警告、80% 中止。任何拒绝统一抛 `XLSX_LIMIT_EXCEEDED` 并带 `{ limit, observed }`，不产出 rows、不写会话状态。

### 工作台双簿四态

拖入两个 `.xlsx` / `.xlsm` 文件，现在与 CSV 一样出 same / added / removed / modified 四态，带逐单元格高亮与逐表计数。合并区锚点、1900 / 1904 日期基准与隐藏行列标注都取自解析 `meta`，「忽略隐藏」开关只重算表、不重读文件。两侧严格顺序解析（先左后右），超限的一对在建 tab 之前即以对比上限文案拒绝。

### 出厂构建能打开工作簿

沙箱 renderer 里没有 `Buffer` / `process` 全局，测试环境能过的工作簿打开在出厂构建里失败。解析层不再依赖这两个全局，并加静态守卫，一旦回归即判红。

### 二次启动按文件参数接管

二次启动会把参数交给已运行实例；当首次启动记录的入口是 `.`、接管时写成绝对路径时，该参数被当作左路径存活，应用目录被当成对比输入。现在两种拼写都经同一规范化去掉应用入口，再以接管进程的工作目录为基准。

## Windows 安装包与免安装 zip

Windows 的打包口径与上一版一致；免安装下载说明见下节。

### Windows 免安装包

Windows 同时提供 NSIS 安装包与免安装 `.zip`，解压即用、无安装步骤。自动更新仍指向 NSIS 安装包，免安装 zip 只作为下载。

## macOS 签名与公证

macOS 包保持 Developer ID 签名与 Apple 公证，签名凭据缺失时 CI fail-closed。本版不改这一口径。

## 不做的事

- 「忽略空白差异」开关仍默认关闭；开启时只吞空格与制表符，行级高亮、行内高亮与差异计数仍读取同一份比较结果，状态栏仍显示原始值。
- 重载仍在原会话读取当前文件对，不新建会话，滚动位置与开关状态保持不变；某一侧读取失败时保留上一次结果。
- 交换仍只对调内容、状态栏原始值、指示条与计数，再次交换即可复原。
- 工作簿对比只读数据：一律不求值公式，`.xls` / `.xlsb` 仍被拒绝，导出与快照格式、目录扫描口径与发布通道不变。
- 本范围内的覆盖率、测试、截图取证与 ratchet 调整属于验证面，不写成用户功能。

## 风险与验证规模

v0.2.25 相对 v0.2.24 的新增部分是工作簿取值层、解析上限与 zip bomb 拒绝层、工作台双簿四态，以及沙箱 renderer 与二次启动参数两条修复。既有家族的比较语义、IPC、导出与快照格式均未改动。验证覆盖解析语义、依赖钉版完整性、上限与 zip bomb 拒绝的错误形状、逐表四态计数、隐藏行列策略、renderer 全局静态守卫、接管参数剥离，以及双语说明通过仓库门禁。本文件不写任何性能或内存数字。

## 升级方式

建议从 v0.2.24 升级：下载 v0.2.25 对应平台的新安装包覆盖安装（macOS `.dmg` / `.zip`，Windows 安装包，Linux `.AppImage` / `.deb`）。Windows 可选 NSIS 安装包，或下载 `OpenCompare-0.2.25-win-x64.zip` 解压即用；自动更新仍只走 NSIS exe。本次不需要迁移数据，已有的会话与设置照常可用。
