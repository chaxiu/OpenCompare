# OpenCompare v0.2.12 发布说明

v0.2.12 是 UI 第一期的发布收敛：窗口壳层按单一尺寸表重排为五级，图标改为仓库内自带的单一出口并移除 `lucide-react`，主题增加亮 / 暗 / 跟随系统三态，会话 tab 标题按长路径截断，README 两版换成真实构建截图。对比与合并算法、目录扫描、快照格式与发布通道都没有改动。

## 本次变化

### 壳层五级重排

- **单一尺寸表**：窗口壳层的高度、间距与分档统一到一张尺寸表，三档宽度对应五级布局，入口清单逐条核对后零丢失。
- **窄窗口工具栏**：目录工作台窄窗口（≤1024）首行工具栏溢出修复。

### 图标单一出口

- **仓库内自带图标**：`ICON_PATHS` / `SHELL_ENTRY_ICONS` / `UI_ICON_ACTIONS` 收敛为一张映射表，界面只从这一出口取图标；lucide-react 已移除，安装与构建不再依赖该包。

### 亮 / 暗 / 跟随系统三态主题

- **三态主题**：亮、暗与跟随系统三态由同一组 `--color-*` token 驱动，切换后即时生效。
- **设置持久化**：主题分区在设置里可选，`UserSettings` 负责持久化；设置文件损坏时回退到默认主题，不阻塞启动。

### 会话 tab 标题截断

- **同源裁剪**：会话 tab 的标题与副标题按同一张三档预算表裁剪，长路径不再挤压相邻 tab；切换会话后标题立即跟随当前会话。

### README 双截图

- **真实构建截图**：两版 README 换成本次构建的界面截图（工作台与文件对比各一张），不再使用占位图。

### 文档收尾

- `docs/ui-phase1-reference-audit.md` 与 `docs/lessons.md` 随同一批改动收尾，设计基线文档同步更新。

## 不做的事

- 不改对比与合并算法：四态语义、行级差异结果与三向合并行为保持原状。
- 不改目录扫描与快照格式：已有会话、设置与快照照常可用。
- 不改发布通道与打包签名配置：tag 触发、三平台构建与签名公证口径不变。

## 风险与验证规模

本版改动集中在渲染层与文档：壳层尺寸表、图标出口、主题 token、会话 tab 文案裁剪与 README 截图；不触碰对比 / 合并 / 扫描算法、文件读写通道与快照格式。

本版没有性能或内存实测，因此本文件不写任何性能数字；相关既有实测结论仍以历史发布说明与证据文件为准。

## 升级方式

建议从 v0.2.11 升级。下载 v0.2.12 对应平台的新安装包覆盖安装（macOS `.dmg` / `.zip`，Windows `OpenCompare-Setup-0.2.12.exe`，Linux `.AppImage` / `.deb`）。签名与公证口径不变：macOS 包经 Developer ID 签名 + Apple 公证，凭据缺失时 fail-closed。本次不需要迁移数据，已有的会话与设置照常可用。
