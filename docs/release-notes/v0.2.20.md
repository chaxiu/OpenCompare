# OpenCompare v0.2.20 release notes

English | [简体中文](https://github.com/chaxiu/OpenCompare/blob/v0.2.20/docs/release-notes/v0.2.20.zh-CN.md)

v0.2.20 converges three user-visible changes already merged into main: comparison history with recent items and one-click reopen, a narrow-window status bar that wraps instead of clipping its legend and counts, and a real three-way merge session entry that keeps its switches across reopen. Beyond these changes, comparison semantics, IPC, export and snapshot formats are untouched.

## What changed

### Comparison history

The history list is now a pure model persisted through the platform port, so the recent items survive a restart. The new page lists recent comparisons, and one click reopens the same file pair, directory pair or merge with its previous switches. Before a recorded path is reopened it is preflighted; a broken path is reported in place and no half-built tree is created. Failed entries stay as error rows that can be removed one by one, the list is capped at 20 mixed records and can be cleared explicitly.

### Status bar wrapping

On a narrow window the status bar wraps to a second row instead of clipping the legend and the counts. The wrapped height comes from the row model, so the bottom of the window never hides a line.

### Three-way merge session

A real merge session can be opened from the workbench and from history. Reopening a merge keeps the left and right switches, and restarting the app restores the same session.

### Release and verification surface

The `src/core` coverage floors are a hard gate in release CI, and the README screenshots were rebuilt on a clean main with their provenance repinned to the renderer zero-diff baseline.

## Windows installer and portable zip

Windows keeps the same packaging contract as the previous release; see the portable download note below.

### Windows portable download

Windows ships both the NSIS installer and a portable `.zip` that runs right after extraction with no installation step. Auto-update keeps resolving to the NSIS installer, so the portable zip is a download only.

## macOS signing and notarization

The macOS build keeps Developer ID signing and Apple notarization, and CI fails closed when the signing credentials are missing. This release does not change that posture.

## Not in this release

- The **ignore whitespace** switch is still off by default, and when it is on only spaces and tabs are swallowed, with highlights and the difference count reading one comparison result while the status bar shows raw values.
- Reload still re-reads the current pair in the same session, so the scroll position and switches stay put, and an unreadable side keeps the previous result.
- The swap action still exchanges content, the ruler and counts and the status bar values, and swapping again restores the original order.
- No changes to export or snapshot formats, directory scanning, the release channel or the three-way merge behavior beyond the entry and reopen work above.
- CI and release-verification work in this range is validation plumbing, not a user feature.

## Risk and verification scope

The change is limited to comparison history, the wrapped status bar and the merge session entry; comparison semantics, IPC, export and snapshot formats are untouched. Verification covers the history add, reopen, preflight, error-row and clear paths, the narrow-window status bar row model and the merge reopen path through the repository gates. This release states no performance or memory numbers.

## Upgrade

Upgrade from v0.2.19. Replace the app with the v0.2.20 package for your platform (macOS `.dmg` / `.zip`, Windows installer, Linux `.AppImage` / `.deb`). On Windows you can either install with the NSIS `.exe` or download `OpenCompare-0.2.20-win-x64.zip` and run it right after extracting; auto-update still only uses the NSIS `.exe`. No data migration is needed; existing sessions and settings keep working.
