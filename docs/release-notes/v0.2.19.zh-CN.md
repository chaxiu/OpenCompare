# OpenCompare v0.2.19 发布说明

[English](https://github.com/chaxiu/OpenCompare/blob/v0.2.19/docs/release-notes/v0.2.19.md) | 简体中文

v0.2.19 收敛三项已合入主干、用户可见的文本对比操作：默认关闭的「忽略空白差异」开关、当前文件对显式重载、左右面板显式交换。除这三项外，比较语义、IPC、导出与快照格式都没有改动。

## 本次变化

### 忽略空白差异

「忽略空白差异」开关默认关闭；开启时只吞空格与制表符，行级高亮、行内高亮与差异计数读取同一份比较结果，面板文本与状态栏仍显示原始值。关闭开关即恢复严格比较。

### 显式重载当前文件对

重载在原会话中重新读取当前左右文件，不新建会话，滚动位置与开关状态保持不变。某一侧读取失败时，错误就地提示，视图保留上一次结果。

### 显式交换左右面板

交换后右侧内容移到左边、左侧内容移到右边：内容、状态栏原始值、指示条与计数一并左右对调。再次交换即可复原。

## Windows 安装包与免安装 zip

Windows 的打包口径与上一版一致；免安装下载说明见下节。

### Windows 免安装包

Windows 同时提供 NSIS 安装包与免安装 `.zip`，解压即用、无安装步骤。自动更新仍指向 NSIS 安装包，免安装 zip 只作为下载。

## macOS 签名与公证

macOS 包保持 Developer ID 签名与 Apple 公证，签名凭据缺失时 CI fail-closed。本版不改这一口径。

## 不做的事

- 除上述三项外不改比较语义与 IPC：四态语义、行级差异结果与三向合并行为保持原状。
- 不改导出与快照格式、目录扫描口径与发布通道。
- 本范围内的 CI 与发布验证提交属于验证面，不写成用户功能。

## 风险与验证规模

本版改动集中在忽略空白差异开关、当前文件对显式重载与左右面板显式交换：比较语义、IPC、导出与快照格式均未改动。验证覆盖双栏文本对比的开关、重载与交换三条路径，均通过仓库门禁。本文件不写任何性能或内存数字。

## 升级方式

建议从 v0.2.18 升级：下载 v0.2.19 对应平台的新安装包覆盖安装（macOS `.dmg` / `.zip`，Windows 安装包，Linux `.AppImage` / `.deb`）。Windows 可选 NSIS 安装包，或下载 `OpenCompare-0.2.19-win-x64.zip` 解压即用；自动更新仍只走 NSIS exe。本次不需要迁移数据，已有的会话与设置照常可用。
