# OpenCompare v0.2.14 发布说明

[English](./v0.2.14.md) | 简体中文

0.2.13 未公开，其内容并入本版。v0.2.14 收敛两项已合入主干的内容与一轮首屏信息架构：结构化语义对比的定位同步补齐单侧新增 / 删除时的祖先回退，结构化语义门的默认矩阵从 9 门扩到 10 门；顶栏常驻动作只剩新建对比 / 打开文件 / 打开文件夹 / 设置，品牌副标题与演示样本入口移除，scene 分段控件退场并由打开的文件夹或文件类型决定 scene，切换会话改由会话 tab 承担，示例移入设置的「示例与调试」，空态只保留三个真实 CTA。对比与合并算法、目录扫描、快照格式与发布通道都没有改动。

## 本次变化

### 顶栏与入口

- **顶栏四个常驻动作**：顶栏只保留新建对比 / 打开文件 / 打开文件夹 / 设置；演示样本按钮与其下拉移除，品牌副标题移除。
- **scene 随打开对象走**：scene 分段控件（视图切换）退场，scene 由打开的文件夹或文件类型决定；切换会话改由会话 tab 承担，tab 按 scene 显示类型图标，壳层入口清单 20 → 18。
- **示例与调试**：设置新增「示例与调试」分区，承载目录、代码 3-way、CSV、JSON-YAML、远端快照 5 类示例并复用既有加载路径；目录工作流工具栏不再带两个演示入口。
- **空态只留真实路径**：空态只保留三个真实 CTA（新建对比 / 打开文件 / 打开文件夹），提示指向「设置 → 示例与调试」。

### P1 语义定位收尾

- **祖先回退**：单侧新增 / 删除时，缺失的一侧落到最近的共同祖先行，并叠加 `opacity-60` 弱化高亮，不再直接丢弃高亮。
- **精确行不回退**：存在精确对应行时仍然精确落位，不回退到祖先。

### 结构化语义门

- **默认门数 9→10**：默认门禁矩阵从 9 门扩到 10 门，结构化 / 语义（`structured` / `semantic`）对比纳入同一套门禁口径。

## 不做的事

- 不改对比与合并算法：四态语义、行级差异结果与三向合并行为保持原状。
- 不改目录扫描、快照格式与发布通道。
- 0.2.13 不单独发布：它从未公开，其内容并入本版。

## 风险与验证规模

本版改动集中在壳层顶栏与首屏、结构化语义视图与门禁矩阵：对比 / 合并 / 扫描算法、文件读写通道与快照格式均未改动。本版没有性能或内存实测，因此本文件不写任何性能数字。

## 升级方式

建议从 v0.2.12 升级：下载 v0.2.14 对应平台的新安装包覆盖安装（macOS `.dmg` / `.zip`，Windows 安装包，Linux `.AppImage` / `.deb`）。本次不需要迁移数据，已有的会话与设置照常可用。签名与公证口径不变：macOS 包经 Developer ID 签名 + Apple 公证，凭据缺失时 fail-closed。
