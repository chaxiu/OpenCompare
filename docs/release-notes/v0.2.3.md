# OpenCompare v0.2.3 发布说明

OpenCompare v0.2.3 修复了真实工程目录里存在悬空符号链接或不可读项时目录对比整体失败的问题：这类条目现在会被跳过并计数，对比照常完成。同批改进大目录内容读取的内存占用。

## 本次修复

### 悬空符号链接 / 不可读项不再中断目录对比

- 目录列举、扫描、对比与快照构建遇到悬空符号链接或不可读项时，不再让整次目录对比失败，改为跳过并计数。
- 工作台就地以 info 提示「已跳过 N 个不可读项/悬空链接」，目录视图同时给出跳过计数，跳过项不进入对比结果。
- 真实工程目录里常见的临时清理残留、失效链接不再阻塞整次对比。

### 大目录内容读取内存下降

- 内容摘要改为摘要直写缓存：对比只保留每份文件的摘要，不再保留正文。
- DawnChat ↔ ZenMind 实测 134 万文件的目录对比，原实现需读 10.67 GiB。

## 升级建议

建议 **v0.2.2 及更早** 的用户升级到 v0.2.3，尤其是对比真实工程目录或大目录的用户——旧版本遇到悬空符号链接 / 不可读项会让整次目录对比失败。

下载 v0.2.3 对应平台的新安装包覆盖安装即可：

- macOS：`.dmg` 或 `.zip`
- Windows：`OpenCompare.Setup.0.2.3.exe`
- Linux：`.AppImage` 或 `.deb`

macOS 安装包经 Developer ID 签名 + Apple 公证流程产出；签名与公证口径与上一版一致，凭据缺失时发版流程会直接失败（fail-closed），不会发布未签名裸包。

## 关于上一个版本

v0.2.2 修复的是大目录对比的文件句柄耗尽（`EMFILE` / `ENFILE`）：目录内容读取、快照内容读取与目录条目遍历改为默认 **8 路有界并发**，句柄耗尽时工作台给出可读提示而不是崩溃。该修复在 v0.2.3 中保持有效，本版未改动并发默认值。

`v0.1.2` 的 tag 与已发布资产保持原样，不删除、不移动、不重打、不替换；v0.2.1 与 v0.2.2 的发布说明保留为历史记录。
