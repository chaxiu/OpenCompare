# OpenCompare v0.2.2 发布说明

OpenCompare v0.2.2 修复了大目录对比时可能耗尽文件句柄的问题：把含数千个文件的真实文件夹拖进目录对比，或加载同等规模的快照，不再因为一次性打开全部文件而崩溃。

## 本次修复

### 大目录对比不再崩溃

- 目录对比内容读取、快照内容读取与目录条目遍历改为默认 **8 路有界并发**，文件句柄占用有上限。
- 含数千个文件的真实文件夹可以正常完成对比，不再因 `EMFILE` 中断。

### 句柄耗尽可读提示

- 系统返回 `EMFILE` / `ENFILE` 时，工作台就地展示「文件句柄耗尽（EMFILE / ENFILE）」的可读提示，不再崩溃窗口。
- 已有的对比、同步与合并结果不受影响。

## 升级建议

建议 **v0.2.1 及更早** 的用户升级到 v0.2.2，尤其是经常对比大目录或加载大快照的用户。

下载 v0.2.2 对应平台的新安装包覆盖安装即可：

- macOS：`.dmg` 或 `.zip`
- Windows：`OpenCompare.Setup.0.2.2.exe`
- Linux：`.AppImage` 或 `.deb`

macOS 安装包经 Developer ID 签名 + Apple 公证流程产出；签名与公证口径与上一版一致，凭据缺失时发版流程会直接失败（fail-closed），不会发布未签名裸包。
