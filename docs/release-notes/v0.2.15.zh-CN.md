# OpenCompare v0.2.15 发布说明

[English](./v0.2.15.md) | 简体中文

v0.2.15 收敛三项已合入主干、用户可见的目录同步改动：目录同步按链接落盘、同步预览摘要跟随删除勾选、两版 README 补齐三条同步口径。对比与合并算法、目录扫描的不跟随链接口径、快照格式与发布通道都没有改动。

## 本次变化

### 按链接落盘

- **源侧独有链接同步后仍是链接**：符号链接按自身落盘，目标串按字面原样写入——相对路径不会被改写为绝对路径，悬空链接照链接落盘，指向目录的链接同样只落链接本身，不跟随、不进入目标子树。
- **替换普通文件不写穿**：目标侧同名普通文件被链接替换时只替换该条目，不写穿它原来指向的外部文件。
- **镜像删除只删链接本身**：勾选镜像删除后，本次只删链接本身，不穿透到链接目标。
- **链接时间对齐**：两侧是同一个链接、仅链接时间不同时，预览把它列为待对齐链接，执行时按链接对齐，不复制内容。

### 预览摘要与删除勾选同源

- **同一份判定**：「本次将执行」计数、执行按钮与不可执行提示由同一份判定得出。镜像删除项默认不勾选，此时可执行数为 0 且执行按钮不可用；勾选一项后为 1 且可用，取消勾选又回到 0。
- **删除组头同时显示计划数与已选数**：镜像删除组头同时给出计划数与已选数。
- **提示的删除数与磁盘实际一致**：完成提示里的删除数取本次执行结果，与磁盘实际一致。

### README 同步口径

- **两版 README 补三条同步口径**：增量同步只做新增与覆盖、不删除；镜像同步额外列出目标侧独有项作为待删除项，删除项默认不勾选、显式勾选后才执行；应用外对目录的改动在下次对比时读取，没有后台文件监听。

## 不做的事

- 不改对比与合并算法：四态语义、行级差异结果与三向合并行为保持原状。
- 不改目录扫描的不跟随链接口径、快照格式与发布通道。

## 风险与验证规模

本版改动集中在目录同步的链接落盘、同步预览摘要与两版 README 的能力行：对比 / 合并 / 扫描算法、四态计数与快照格式均未改动。本文件不写任何性能或内存数字。

## 升级方式

建议从 v0.2.14 升级：下载 v0.2.15 对应平台的新安装包覆盖安装（macOS `.dmg` / `.zip`，Windows 安装包，Linux `.AppImage` / `.deb`）。本次不需要迁移数据，已有的会话与设置照常可用。签名与公证口径不变：macOS 包经 Developer ID 签名 + Apple 公证，凭据缺失时 fail-closed。
