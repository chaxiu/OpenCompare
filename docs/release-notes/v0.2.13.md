# OpenCompare v0.2.13 release notes

English | [简体中文](./v0.2.13.zh-CN.md)

v0.2.13 is a wrap-up of two changes already merged into main: the structured semantic comparison location sync now falls back to the nearest common ancestor when one side adds or removes lines, and the default structured semantics gate matrix grows from 9 gates to 10. The diff and merge algorithms, directory scanning, snapshot format and release channel are unchanged.

## What changed

### P1 semantic location wrap-up

- **Ancestor fallback**: when a line exists on only one side, the missing side falls back to the nearest common ancestor line and adds the `opacity-60` weakened highlight instead of dropping the highlight.
- **Exact lines do not regress**: when an exact counterpart line exists, the highlight still lands on that line and never falls back to an ancestor.

### Structured semantics gate

- **Default matrix 9→10**: the default gate matrix grows from 9 gates to 10, covering structured / semantic (`structured` / `semantic`) comparison under the same gate posture.

## Not in this release

- No changes to the diff and merge algorithms: the four-state semantics, line diff results and three-way merge behavior are unchanged.
- No changes to directory scanning, the snapshot format or the release channel.
- This release ships with v0.2.13 and is not published yet.

## Risk and verification scope

The changes are limited to the structured semantic view and the gate matrix; the diff / merge / scanning algorithms, file I/O and snapshot format are untouched. This release has no performance or memory measurement, so this file states no measured numbers.

## Upgrade

Upgrade from v0.2.12. Replace the app with the v0.2.13 package for your platform (macOS `.dmg` / `.zip`, Windows installer, Linux `.AppImage` / `.deb`). No data migration is needed; existing sessions and settings keep working. The signing posture is unchanged: the macOS build is Developer ID signed and Apple-notarized, and CI fails closed when credentials are missing.
