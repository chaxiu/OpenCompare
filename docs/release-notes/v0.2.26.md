# OpenCompare v0.2.26 release notes

English | [简体中文](https://github.com/chaxiu/OpenCompare/blob/v0.2.26/docs/release-notes/v0.2.26.zh-CN.md)

v0.2.26 is a maintenance release with one user-visible change on the welcome screen: the recent comparisons list shows at most 5 entries, an "All N" button opens a dialog with every stored entry (the history keeps at most 20), and the empty state explains how to start in a single sentence. Comparison semantics, IPC, export and snapshot formats are unchanged.

## What changed

### Recent comparisons at most 5

The welcome screen keeps the five newest comparisons on the page. When the history holds more than five entries, an "All N" button appears next to the "Clear history" action, where N is the number of stored comparisons; below five entries the button is absent. The list order stays newest first, and reopening or removing a row from the short list behaves exactly as before.

### The "All N" dialog

The "All N" button opens a dialog titled "All N recent comparisons" and lists every stored comparison, which the history caps at 20 entries. Reopen and remove work per row inside the dialog, and closing it returns focus to the button that opened it, so keyboard navigation stays on the welcome screen.

### A single-sentence empty state

The empty state now reads "Drag files or folders into both sides, or click \"New comparison\" to enter the paths." One sentence replaces the previous paragraph, keeps both entry points, and leaves the built-in samples note unchanged.

### Release engineering only

The rest of this range has no user-visible effect. The version anchors are converged in one place (the package version, the top changelog section, the bilingual notes and the workflow dispatch default tag), while the READMEs keep pointing at the public v0.2.25 build until this tag ships. One commit re-pins the screenshot provenance, one raises the repository test-line ceiling that the empty-state home coverage needs, and one classifies shell signal exits as retryable environment failures. Nothing here changes a comparison result.

## Windows installer and portable zip

Windows keeps the same packaging contract as the previous release; see the portable download note below.

### Windows portable download

Windows ships both the NSIS installer and a portable `.zip` that runs right after extraction with no installation step. Auto-update keeps resolving to the NSIS installer, so the portable zip is a download only.

## macOS signing and notarization

The macOS build keeps Developer ID signing and Apple notarization, and CI fails closed when the signing credentials are missing. This release does not change that posture.

## Not in this release

- The **ignore whitespace** switch is still off by default, and when it is on only spaces and tabs are swallowed, with highlights and the difference count reading one comparison result while the status bar shows raw values.
- Reload still re-reads the current pair in the same session, so the scroll position and switches stay put, and an unreadable side keeps the previous result.
- The swap action still exchanges content, the ruler and counts and the status bar values, and swapping again restores the original order.
- Workbook comparison keeps the v0.2.25 posture: `.xlsx` / `.xlsm` files still compare as four-state tables, formulas are never evaluated, the SheetJS parse layer is unchanged, and an over-limit container is still rejected with `XLSX_LIMIT_EXCEEDED`, zip bomb included. The shipped renderer still parses workbooks without `Buffer` or `process` globals, and a second launch still strips the app entry from its argument before taking over.
- Export and snapshot formats, directory scanning and the release channel are unchanged.

## Risk and verification scope

The only new user-facing surface in v0.2.26 relative to v0.2.25 is the welcome screen: the five-entry cap, the "All N" dialog, and the single-sentence empty state. Verification covers the cap and the dialog with the full 20 stored entries, the empty-state copy in both languages, and the version anchors across the package version, changelog, notes and workflow default tag. Comparison semantics for text, code, directory, CSV and workbook families, IPC, export and snapshot formats are untouched. This release states no performance or memory numbers.

## Upgrade

Upgrade from v0.2.25. Replace the app with the v0.2.26 package for your platform (macOS `.dmg` / `.zip`, Windows installer, Linux `.AppImage` / `.deb`). On Windows you can either install with the NSIS `.exe` or download `OpenCompare-0.2.26-win-x64.zip` and run it right after extracting; auto-update still only uses the NSIS `.exe`. No data migration is needed; existing sessions and settings keep working.
