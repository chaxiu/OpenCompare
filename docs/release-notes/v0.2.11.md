# OpenCompare v0.2.11 发布说明

v0.2.11 带来两项面向用户的变化：双栏文本 / 代码对比的侧边新增一条常驻的竖向四态差异指示条，点选跳转在大行数双栏上已实测可用；大行数双栏对比改为可视窗口渲染，350,000 行文本模型（源码拼接）下只渲染视口内的行元素。三向合并侧不显示指示条；对比与合并算法、目录扫描与快照格式都没有改动。

## 本次变化

### 双栏 diff 侧边常驻竖向四态差异指示条

- **四态聚合**：指示条按本次对比已经算出的行级 `same` / `added` / `removed` / `modified` 四态聚合，把有差异的行（新增 / 删除 / 修改）在窄条上按对应状态标出，相同行不着色。
- **常驻可见**：内置样本、目录下钻、拖放与打开文件进入的双栏对比都带这条指示条；切到三向合并（三栏）时不显示。
- **随滚动同步**：滚动任一栏时，指示条上的视口窗跟随移动，标出的差异位置与对应行号不变。
- **点选跳转（已实测）**：点选指示条上的标记会选中对应的差异块，两栏同步滚动到该块首行，工具栏的差异计数与标记同步；指示条可聚焦，方向键在差异块之间循环，回车重新定位当前块；键盘导航（方向键 / 回车）本次实测未覆盖。在 350,000 行文本模型（源码拼接）的双栏对比上，指示条 track 608px、bandHeight 4：点击中部空白区即选中最临近的差异块，active 从 1 变为 106/210，两栏 scrollTop 相等且等于块首行 × 20，即 3,590,120 = 179,506 × 20；顶部与末端再各点一次，顶部 active 1/210、scrollTop 20，末端 active 209/210、scrollTop 6,967,840，两次两栏 scrollTop 均相等；选中块的描边为 rgb(76,141,255)。实测来源：run `trun_08764efa44c39426` / commit `2bcdc53e`。
- **零差异文件为纯 NO-OP**：两侧各 5,000 行完全相同的 0 差异文件点击为纯 NO-OP：不抛错、不跳到第 0 行，scrollTop 0 → 0。

### 大行数双栏改为可视窗口渲染

- **窗口渲染**：双栏 diff 不再为全部行创建行元素，只渲染视口内的行与少量上下缓冲。350,000 行文本模型（源码拼接）下单栏实际渲染的行元素为 39–49 个，与总行数无关。
- **内容高度**：滚动条总高仍按真实内容计算——总高 7,003,040px = 350,152 对齐行 × 20；350,152 是内部对齐行数（含 150 行 filler 补齐右侧插入块），两栏严格相等，不是单侧源文件行数。
- **内存与首开**：本次实测 renderer 峰值 451.6 MiB、应用总峰值 909.0 MiB，均低于本版护栏 renderer 2.25 GiB / 应用总 2.5 GiB；无 OOM，无 renderer 重启。350,000 行文本模型（源码拼接）首开 ready 471 ms，热重开 209 ms。

修复前对照（另一次实测）：同一夹具在修复前的 commit `4166c9b9` / run `trun_d63c3971b06ccfca` 上，单栏渲染 350,152 行 DOM，renderer 峰值 9.29 GiB、应用总峰值 9.62 GiB；这组修复前数字不与上面本版数字混算。

## CI 测试稳定性修复

`src/renderer/src/components/DiffRuler.scale.test.tsx` 里那条「每个非 same 行都被同状态标记覆盖」的 358,000 行同步遍历用例，此前走 vitest 默认 5000ms per-test 超时。CI attempt1 实测该用例耗时 6,816ms，撞上默认上限被判超时；同版本本机全量 `pnpm test` 为 27.42s / 69 files / 1104 passed。差异来自 runner 速度，不是产品逻辑回归。

- **显式超时**：该用例现在带显式 `30_000` per-test 超时（第三参数），相对 CI 实测 6,816ms 约 4.4x 余量；全局 `testTimeout` / `hookTimeout` 未改，其它用例仍走默认 5000ms。
- **规模与断言不变**：358,000 行同步遍历规模、用例数量与逐行覆盖断言全部保留，没有删用例、跳过、缩小规模或放宽断言。
- **不改产品行为**：本次只改测试文件的超时参数，产品代码、对比 / 合并算法与运行时行为都不受影响。

## 不做的事

- 不做文本缩略图 / minimap 渲染：指示条只画状态标记与视口窗，不渲染任何行内文字或代码缩略。
- 不新增扫描或哈希：指示条复用本次对比已算出的行级差异结果，不额外读取文件、不重新扫描目录、不计算哈希。
- 不改对比与合并算法：四态语义、行级差异结果与三向合并行为保持原状；三向合并侧不显示指示条。
- 不改快照格式与文件读写通道：已有会话、设置与快照照常可用。

## 风险与验证规模

本版改动只落在渲染层：指示条、点选 / 键盘跳转接线、双栏窗口渲染与内容高度计算；不触碰对比 / 合并 / 扫描算法、文件读写通道与快照格式。

已实测两项，来源统一为 run `trun_08764efa44c39426` / commit `2bcdc53e`：350,000 行文本模型（源码拼接）下的指示条 track 级点选与顶部 / 末端跳转、零差异文件的点击行为；以及同规模下双栏窗口渲染的行元素数量、内容总高、内存与首开数据。具体数值见上一节。

未覆盖：目录对比在条目规模上的表现、HTML 报告导出、原生保存面板的手工操作，本场都没有实测结论；这些项目属于另版实测或仍待后续场次，本文件不为它们写任何数值，也不引用其它版本的规模数字。

## 升级方式

建议从 v0.2.9 升级。下载 v0.2.11 对应平台的新安装包覆盖安装（macOS `.dmg` / `.zip`，Windows `OpenCompare-Setup-0.2.11.exe`，Linux `.AppImage` / `.deb`）。签名与公证口径不变：macOS 包经 Developer ID 签名 + Apple 公证，凭据缺失时 fail-closed。本次不需要迁移数据，已有的会话与设置照常可用。
