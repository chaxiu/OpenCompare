# OpenCompare v0.2.20 发布说明

[English](https://github.com/chaxiu/OpenCompare/blob/v0.2.20/docs/release-notes/v0.2.20.md) | 简体中文

v0.2.20 收敛三项已合入主干、用户可见的改动：对比历史与最近记录、一键重开；窄窗口状态栏改为换行而不裁切图例与计数；以及真实三向合并会话入口在重开后保持开关。除这些改动外，比较语义、IPC、导出与快照格式都没有改动。

## 本次变化

### 对比历史

历史清单改为纯模型并经平台通道持久化，重启后最近记录仍在。新建页列出最近的对比，点击一次即可按原开关重开同一文件对、目录对或合并。重开前先做路径预检：坏路径就地提示，不建半棵树。失败条目以错误行保留，可逐条移除；清单上限 20 条混合记录，可显式清空。

### 状态栏换行

窄窗口下状态栏换到第二行，不再裁切图例与计数；换行后的高度取自行模型，窗口底部不会藏住一行。

### 三向合并会话

真实合并会话可从工作台与历史进入；重开合并时保持左右开关，重启应用后仍能恢复同一会话。

### 发布与验证面

`src/core` 覆盖率地板成为 release CI 的硬门；README 截图在干净的 main 上重建，provenance 重钉到渲染器零差异基线。

## Windows 安装包与免安装 zip

Windows 的打包口径与上一版一致；免安装下载说明见下节。

### Windows 免安装包

Windows 同时提供 NSIS 安装包与免安装 `.zip`，解压即用、无安装步骤。自动更新仍指向 NSIS 安装包，免安装 zip 只作为下载。

## macOS 签名与公证

macOS 包保持 Developer ID 签名与 Apple 公证，签名凭据缺失时 CI fail-closed。本版不改这一口径。

## 不做的事

- 「忽略空白差异」开关仍默认关闭；开启时只吞空格与制表符，行级高亮、行内高亮与差异计数仍读取同一份比较结果，状态栏仍显示原始值。
- 重载仍在原会话读取当前文件对，不新建会话，滚动位置与开关状态保持不变；某一侧读取失败时保留上一次结果。
- 交换仍只对调内容、状态栏原始值、指示条与计数，再次交换即可复原。
- 不改导出与快照格式、目录扫描口径与发布通道；除上述入口与重开工作外，三向合并行为保持原状。
- 本范围内的 CI 与发布验证提交属于验证面，不写成用户功能。

## 风险与验证规模

本版改动集中在对比历史、状态栏换行与合并会话入口：比较语义、IPC、导出与快照格式均未改动。验证覆盖历史的添加、重开、预检、错误行与清空路径，窄窗口状态栏的行模型，以及合并重开路径，均通过仓库门禁。本文件不写任何性能或内存数字。

## 升级方式

建议从 v0.2.19 升级：下载 v0.2.20 对应平台的新安装包覆盖安装（macOS `.dmg` / `.zip`，Windows 安装包，Linux `.AppImage` / `.deb`）。Windows 可选 NSIS 安装包，或下载 `OpenCompare-0.2.20-win-x64.zip` 解压即用；自动更新仍只走 NSIS exe。本次不需要迁移数据，已有的会话与设置照常可用。
