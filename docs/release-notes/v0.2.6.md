# OpenCompare v0.2.6 发布说明

OpenCompare v0.2.6 修复 Windows 绝对路径在四个入口被错误拼接到当前工作目录（cwd）/ baseDir 的问题。本版不新增功能，macOS 与 Linux 行为不变，对比结果与快照格式保持不变。

## 本次修复

### Windows 绝对路径在四个入口按原样解析

- **四个入口**：CLI 参数（`--left` / `--right`）、单实例接管（应用已运行时再次启动）、新建对比的手工输入、`opencompare://compare` 链接。
- **盘符路径**：`C:\Users\…` 这类盘符绝对路径不再被拼到 cwd / baseDir，按原样解析；盘符大小写保持原样。
- **盘根**：`C:\` 等盘根输入保持盘根语义，`..` 不越过盘根。
- **UNC 共享路径**：`\\server\share\…` 按共享根解析，`..` 不越过共享根；规范形式为 `//server/share/…`。
- **输出口径**：解析成功的结果统一以 `/` 输出（例如 `C:/Users/…`、`//server/share/b.txt`）；`win32` 上的错误回显仍用 `\`，与系统路径习惯一致。

## 升级方式

建议 **v0.2.5 及更早** 的用户升级到 v0.2.6，尤其是需要在 Windows 上通过启动参数、单实例接管、手工输入或 `opencompare://` 链接打开盘符 / 盘根 / UNC 路径的用户。

下载 v0.2.6 对应平台的新安装包覆盖安装即可：

- macOS：`.dmg` 或 `.zip`
- Windows：`OpenCompare-Setup-0.2.6.exe`
- Linux：`.AppImage` 或 `.deb`

macOS 安装包经 Developer ID 签名 + Apple 公证流程产出；签名与公证口径与上一版一致，凭据缺失时发版流程会直接失败（fail-closed），不会发布未签名裸包。
