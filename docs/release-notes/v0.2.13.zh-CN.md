# OpenCompare v0.2.13 发布说明

[English](./v0.2.13.md) | 简体中文

v0.2.13 是两项已合入主干内容的收口：结构化语义对比的定位同步补齐单侧新增 / 删除时的祖先回退，结构化语义门的默认矩阵从 9 门扩到 10 门。对比与合并算法、目录扫描、快照格式与发布通道都没有改动。

## 本次变化

### P1 语义定位收尾

- **祖先回退**：单侧新增 / 删除时，缺失的一侧落到最近的共同祖先行，并叠加 `opacity-60` 弱化高亮，不再直接丢弃高亮。
- **精确行不回退**：存在精确对应行时仍然精确落位，不回退到祖先。

### 结构化语义门

- **默认门数 9→10**：默认门禁矩阵从 9 门扩到 10 门，结构化 / 语义（`structured` / `semantic`）对比纳入同一套门禁口径。

## 不做的事

- 不改对比与合并算法：四态语义、行级差异结果与三向合并行为保持原状。
- 不改目录扫描、快照格式与发布通道。
- 本版随 v0.2.13 交付，尚未发布。

## 风险与验证规模

本版改动集中在结构化语义视图与门禁矩阵：对比 / 合并 / 扫描算法、文件读写通道与快照格式均未改动。本版没有性能或内存实测，因此本文件不写任何性能数字。

## 升级方式

建议从 v0.2.12 升级：下载 v0.2.13 对应平台的新安装包覆盖安装（macOS `.dmg` / `.zip`，Windows 安装包，Linux `.AppImage` / `.deb`）。本次不需要迁移数据，已有的会话与设置照常可用。签名与公证口径不变：macOS 包经 Developer ID 签名 + Apple 公证，凭据缺失时 fail-closed。
