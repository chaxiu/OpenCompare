# OpenCompare v0.2.1 发布说明

OpenCompare v0.2.1 让「开始对比」少一步：不再必须经过系统文件选择器，直接给出左右两个真实路径就能建立对比，也可以从启动参数或 `opencompare://` 链接直达。本版同时把文件保存改为原位写回，并换上 OpenCompare 自己的品牌图标。

> v0.2.0 从未公开发布，本版是它的首发替代，用户可见变化与 v0.2.0 完全相同。

## 本次更新

### 顶栏常驻「新建对比」

- 空态和已有会话时，顶栏都有「新建对比」入口，不会再因为打开了会话而消失。
- 一个入口做三件事：打开文件、打开文件夹、直接输入或粘贴左右路径。
- 快捷键：`Cmd/Ctrl+N` 打开，`Enter` 提交，`Esc` 关闭。

### 免弹窗的路径直传

- 左右路径可直接粘贴或键入，提交时不触发任何打开 / 保存对话框。
- 支持含空格、中文、Unicode 的路径，带引号包裹的路径，`~` 开头的家目录路径，以及相对路径。
- 提交前先校验：两侧都存在且类型一致（文件对文件 / 目录对目录）才建会话；失败会就地提示具体原因，不会建立空会话，也不会替换你正在看的会话。
- 目录对进入目录对比，文件对按扩展名进入代码 / 文本、CSV / TSV、JSON / YAML 视图。

### 启动参数与 `opencompare://` 链接

- 支持 `--left <path> --right <path>`（也支持 `--left=<path>` 形式）直接打开对比。
- 支持 `opencompare://compare?left=<encoded>&right=<encoded>` 链接，空格、中文与 Unicode 不会丢失。
- 冷启动时请求会排队到窗口就绪；应用已在运行时，再启动或再点链接会聚焦已有窗口并接管该请求，不会另开空窗口。

### 文件会话原位写回

- 代码 / CSV / JSON·YAML 文件会话的「保存左/右文件」直接写回当前已加载的真实路径，不再弹系统保存对话框，保存后提示写回路径。
- 目录同步仍按既有 Dry-run 预览后直接执行；合并结果与目录快照导出仍使用系统保存对话框。

### 品牌图标与关于面板

- 窗口、macOS dock、macOS / Windows / Linux 安装包与「关于」面板使用同一套 OpenCompare 品牌图标、应用名与版本号。
- 不会再出现 Electron 默认图标或默认品牌信息。

## 升级方式

下载 v0.2.1 对应平台的新安装包覆盖安装即可：

- macOS：`.dmg` 或 `.zip`
- Windows：`OpenCompare.Setup.0.2.1.exe`
- Linux：`.AppImage` 或 `.deb`

macOS 安装包经 Developer ID 签名 + Apple 公证流程产出；签名与公证口径与上一版一致，凭据缺失时发版流程会直接失败（fail-closed），不会发布未签名裸包。

## 关于上一个版本

`v0.1.2` 的 tag 与已发布资产保持原样，不删除、不移动、不重打、不替换；该 tag 之后的签名与打包修复统一由 v0.2.1 承接。`v0.2.0` 从未公开发布，其发布说明保留为历史记录。
