# OpenCompare v0.2.7 发布说明

OpenCompare v0.2.7 带来两类面向用户的变化：桌面端界面支持中英双语，以及 README 精简为 9 节双语门面。对比算法、目录扫描、快照格式与发布流程均未改动。

## 本次变化

### 桌面端 UI 中英双语

- **首启语言**：首次启动按系统语言决定界面语言——`zh` 开头（如 `zh-CN` / `zh-TW`）显示中文，其余区域以及无法识别系统语言的情况显示英文。
- **设置内切换**：设置面板提供语言选项，选择结果持久化保存，下次启动沿用。
- **即时生效**：切换语言后整个窗口立即按新语言重绘，无需重启应用。
- **不打断工作**：切换语言保留当前会话状态，不关闭已打开的对比，也不重新扫描目录或校验内容。

### README 精简为 9 节双语门面

- **9 节结构**：README 保留下载安装、核心能力、快速上手、环境要求与开发、项目结构、已知问题、证据与文档、Kill Paid Apps 001 平替、许可共 9 节；中英两版保持同构镜像。
- **细节外置**：发布流程移入 `docs/release-process.md`，macOS 签名与公证移入 `docs/release-signing.md`，内存实测数字移入 `docs/perf/` 下的专文，README 只作门面。
- **已知问题只留未修项**：已修复的历史问题保留在对应版本的发布说明里，不再堆积在 README。

## 升级方式

建议 **v0.2.6 及更早** 的用户升级到 v0.2.7。本次升级不改变对比结果、快照格式与本地设置结构。

下载 v0.2.7 对应平台的新安装包覆盖安装即可：

- macOS：`.dmg` 或 `.zip`
- Windows：`OpenCompare-Setup-0.2.7.exe`
- Linux：`.AppImage` 或 `.deb`

macOS 安装包经 Developer ID 签名 + Apple 公证流程产出；签名与公证口径与上一版一致，凭据缺失时发版流程会直接失败（fail-closed），不会发布未签名裸包。
