# OpenCompare v0.2.17 release notes

English | [简体中文](https://github.com/chaxiu/OpenCompare/blob/v0.2.17/docs/release-notes/v0.2.17.zh-CN.md)

v0.2.17 converges two user-visible template-placement and safety changes already merged into main: each row now shows its action and copies unless a move is explicitly checked, and case-insensitive collisions fold to one slot while escaping paths are refused. The diff and merge algorithms, directory scanning, the snapshot format and the release channel are unchanged.

## What changed

### Template placement rows show and choose their action

- **Actions column**: every source-bearing row now carries an `Actions` column and copies by default; a row moves only when its move box is explicitly checked, so a dry-run never turns a check into a silent move.
- **Verified move**: after the write and before the source is deleted, the target must match the source `sha256` and whole-second `mtimeSec`. A failed check keeps both the source and the target and runs no rollback, while the remaining rows still finish.

### Case-insensitive collisions and path containment

- **Case-fold collisions fold to one slot**: on case-insensitive volumes `Logo.png` and `logo.png` resolve to the same slot; several case variants with different content stay a conflict instead of overwriting silently.
- **Path escape refused**: absolute slot paths, drive letters and `..` segments are rejected before any write, so a crafted template cannot write outside the output root.

## Windows installer and portable zip

### Windows portable download

Windows ships both the NSIS installer and a portable `.zip` that runs right after extraction with no installation step. Auto-update keeps resolving to the NSIS installer, so the portable zip is a download only.

## macOS signing and notarization

The macOS build is Developer ID signed and Apple-notarized, and CI fails closed when the signing credentials are missing. This release does not change the signing or notarization configuration.

## Not in this release

- No changes to the diff and merge algorithms: the four-state semantics, line diff results and three-way merge behavior are unchanged.
- No changes to directory scanning, the snapshot format or the release channel.
- The gate matrix, end-to-end fixtures and baseline documents stay on the verification side and are not new user features.

## Risk and verification scope

The changes are limited to the template placement action column and explicit move, and to the case-fold collision and path containment guards; the diff / merge / scanning algorithms, the four-state counts and the snapshot format are untouched. This release states no performance or memory numbers.

## Upgrade

Upgrade from v0.2.16. Replace the app with the v0.2.17 package for your platform (macOS `.dmg` / `.zip`, Windows installer, Linux `.AppImage` / `.deb`). On Windows you can either install with the NSIS `.exe` or download `OpenCompare-0.2.17-win-x64.zip` and run it right after extracting; auto-update still only uses the NSIS `.exe`. No data migration is needed; existing sessions and settings keep working. The signing posture is unchanged: the macOS build is Developer ID signed and Apple-notarized, and CI fails closed when credentials are missing.
