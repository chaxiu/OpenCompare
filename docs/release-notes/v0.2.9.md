# OpenCompare v0.2.9 发布说明

OpenCompare v0.2.9 是本窗口的收口版本：目录对比 HTML 报告改为异步导出并支持进度与取消，对比会话标签页的标题与副标题随会话事实实时派生，保存落盘改为原子写入并给出可读的写入错误。报告的行数与字节上限沿用 v0.2.8 的既有口径，本版只作重述。对比算法、目录扫描与快照格式均未改动。

## 本次变化

### 目录对比 HTML 报告：异步导出、进度与取消

- **异步分块生成**：导出不再一次性阻塞界面，而是分块生成，进度就地显示为「正在导出 x / y 行」，可随时取消。
- **取消不落盘**：取消之后不弹系统保存框、不写任何文件，工作台保持取消前的状态；已保存 / 已取消 / 失败三种结果分别给出明确提示。
- **报告格式不变**：产物仍是自包含单文件 HTML，内联 CSS、无 JS、无外链 CSS / 字体 / 图片，也不引用任何 http(s) 资源，用 `file://` 直接打开即可阅读，无需联网或安装其它软件。
- **路径隐私不变**：左右路径默认相对化到公共祖先，并默认开启「隐藏本机路径」开关，报告里只出现相对路径或目录名；报告顶部固定一行「由本机生成，分享前自查路径」。
- **统计与语言同源**：报告保留相同 / 新增 / 删除 / 修改四态计数与应用版本，取自与界面同一状态源；`<html lang>` 跟随当前界面语言，中英界面下读屏与翻译工具都能正确识别。

### 会话标签页标题与副标题随会话事实派生

- **实时跟随**：切换路径、换文件或从目录对比下钻返回后，标签页标题与路径副标题立即跟随当前会话，不再滞留创建时的文案。
- **同名文件可区分**：同名但位于不同目录的文件对在标签页里显示各自的完整路径。

### 保存落盘原子化与可读写入错误

- **原子写入**：保存先写同目录临时文件，再以 rename 替换目标文件；失败时清理临时文件，不再留下半截文件。
- **可读错误**：写入失败时给出可读原因（磁盘空间不足 / 只读 / 目标是目录），不再只有底层错误码。

### 报告上限与截断口径（沿用 v0.2.8）

- 单份报告行数上限 200,000、字节上限 10 MB，均为 v0.2.8 起的既有口径，本版沿用不变；发生截断时报告内写明「已展示 N / 原始 M（已截断）」，并提示完整清单请在本机查看。

### 品牌与入口保持不变

- 对外品牌与入口仍为 Open Rebuilds（<https://github.com/munk-sh/open-rebuilds>）；安装包品牌、`appId`、`productName`、快照格式与发布通道都不变。

## 升级方式

建议 v0.2.8 及更早的用户升级到 v0.2.9。本次升级不改变对比结果、快照格式与本地设置结构。

下载 v0.2.9 对应平台的新安装包覆盖安装即可：

- macOS：`.dmg` 或 `.zip`
- Windows：`OpenCompare-Setup-0.2.9.exe`
- Linux：`.AppImage` 或 `.deb`

macOS 安装包经 Developer ID 签名 + Apple 公证流程产出；签名与公证口径不变，凭据缺失时发版流程会直接失败（fail-closed），不会发布未签名裸包。
