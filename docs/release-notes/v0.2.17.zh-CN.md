# OpenCompare v0.2.17 发布说明

[English](https://github.com/chaxiu/OpenCompare/blob/v0.2.17/docs/release-notes/v0.2.17.md) | 简体中文

v0.2.17 收敛两项已合入主干、用户可见的模板归位与安全改动：逐条动作列且默认复制、显式勾选才移动，大小写不敏感碰撞折叠并拒绝路径越界。对比与合并算法、目录扫描口径、快照格式与发布通道都没有改动。

## 本次变化

### 模板归位逐条动作列与显式移动

- **动作列**：每个带源的行新增 `Actions` 列并默认复制；只有显式勾选移动的行才移动，Dry-run 不会把一次勾选变成静默移动。
- **移动校验**：写入之后、删除源之前，目标必须与源的 `sha256` 和整秒 `mtimeSec` 一致；任一校验失败即保留源与目标、不执行回滚，其余行继续完成。

### 大小写不敏感碰撞与路径越界防护

- **碰撞折叠**：大小写不敏感卷上 `Logo.png` 与 `logo.png` 折叠到同一槽位；多个大小写变体且内容不同时保持冲突，不静默覆盖。
- **路径越界拒绝**：绝对路径、盘符与 `..` 段在任何写入前即被拒绝，构造出的模板无法写出输出根。

## Windows 安装包与免安装 zip

### Windows 免安装包

Windows 同时提供 NSIS 安装包与免安装 `.zip`，解压即用、无安装步骤。自动更新仍指向 NSIS 安装包，免安装 zip 只作为下载。

## macOS 签名与公证

macOS 包经 Developer ID 签名 + Apple 公证；签名凭据缺失时 CI fail-closed。本版未改动签名与公证配置。

## 不做的事

- 不改对比与合并算法：四态语义、行级差异结果与三向合并行为保持原状。
- 不改目录扫描口径、快照格式与发布通道。
- 门禁矩阵、e2e 夹具与基线文档属于验证面，不写成新的用户功能。

## 风险与验证规模

本版改动集中在模板归位的动作列与显式移动，以及大小写折叠与路径包含防护：对比 / 合并 / 扫描算法、四态计数与快照格式均未改动。本文件不写任何性能或内存数字。

## 升级方式

建议从 v0.2.16 升级：下载 v0.2.17 对应平台的新安装包覆盖安装（macOS `.dmg` / `.zip`，Windows 安装包，Linux `.AppImage` / `.deb`）。Windows 可选 NSIS 安装包，或下载 `OpenCompare-0.2.17-win-x64.zip` 解压即用；自动更新仍只走 NSIS exe。本次不需要迁移数据，已有的会话与设置照常可用。签名与公证口径不变：macOS 包经 Developer ID 签名 + Apple 公证，凭据缺失时 fail-closed。
