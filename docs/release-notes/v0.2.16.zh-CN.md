# OpenCompare v0.2.16 发布说明

[English](https://github.com/chaxiu/OpenCompare/blob/v0.2.16/docs/release-notes/v0.2.16.md) | 简体中文

v0.2.16 收敛五项已合入主干、用户可见的目录与界面改动：目录独有状态改用「左独有 / 右独有」词表、模板归位接入真实用户目录、重复 Dry-run 对已落位槽位幂等、失败提示随界面语言本地化、样本入口收进设置。对比与合并算法、目录扫描口径、快照格式与发布通道都没有改动。

## 本次变化

### 目录独有状态词表

- **左独有 / 右独有**：目录对比行徽标、目录工具栏图例与壳层状态栏图例统一复用过滤页签词表——新增项显示为「右独有」（`Right only`），删除项显示为「左独有」（`Left only`）；文本与代码 diff 的「新增 / 删除」词表保持不变，过滤与四态计数语义不变。

### 模板归位接入真实用户目录

- **先选根**：目录会话点「模板归位」后先选根——模板 A 只读取当前左侧根；散乱树 B 的根与输出根可用系统目录选择器、拖入目录或键入路径（`~` 展开）指定，输出根尚不存在时标注「将创建」。
- **Dry-run 零写入**：计划基于输出根真实既有文件与目录生成，预览不写任何文件；四类分区逐条显示槽位与源，默认勾选、可执行数与确认按钮读同一份解析结果，确认只写已勾选条目。
- **写入后逐条复核**：每个写入项按源 `modifiedMs` 落盘，并逐条复核 sha256 与 `mtimeSec`。

### 重复 Dry-run 幂等

- **已落位**：输出根同名文件内容 sha256 与源一致时判为「已落位」（`Already placed`），不再显示覆盖提示、默认不勾选、也不进入可执行清单；没有可执行项时确认按钮不可用；内容被改动后回到冲突或覆盖保护。

### 失败提示随界面语言本地化

- **保留目标路径与 OS code**：同步写入拒绝与写入后刷新失败按稳定系统码映射到中 / 英词典，保留目标路径与 OS code；模板归位的预检拒绝、逐条写入失败与复核失败同样按当前界面语言显示；英文界面不再出现主进程中文句。

### 样本入口收进设置

- **只在「设置 → 示例与调试」**：首屏与目录工具栏不再出现内置样本路径；内置样本、远端快照示例与失败演示统一从「设置 → 示例与调试」进入。

### Windows 免安装包

Windows 同时提供 NSIS 安装包与免安装 `.zip`（解压即用，无安装步骤）。自动更新仍指向 NSIS 安装包，免安装 zip 只作为下载。

## 不做的事

- 不改对比与合并算法：四态语义、行级差异结果与三向合并行为保持原状。
- 不改目录扫描口径、快照格式与发布通道。
- 门禁矩阵、e2e 夹具与基线文档属于验证面，不写成新的用户功能。

## 风险与验证规模

本版改动集中在目录独有状态词表、模板归位选根与 Dry-run、已落位判定、失败提示本地化与样本入口：对比 / 合并 / 扫描算法、四态计数与快照格式均未改动。本文件不写任何性能或内存数字。

## 升级方式

建议从 v0.2.15 升级：下载 v0.2.16 对应平台的新安装包覆盖安装（macOS `.dmg` / `.zip`，Windows 安装包，Linux `.AppImage` / `.deb`）。Windows 可选 NSIS 安装包，或下载 `OpenCompare-0.2.16-win-x64.zip` 解压即用；自动更新仍只走 NSIS exe。本次不需要迁移数据，已有的会话与设置照常可用。签名与公证口径不变：macOS 包经 Developer ID 签名 + Apple 公证，凭据缺失时 fail-closed。
