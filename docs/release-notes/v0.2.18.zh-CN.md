# OpenCompare v0.2.18 发布说明

[English](https://github.com/chaxiu/OpenCompare/blob/v0.2.18/docs/release-notes/v0.2.18.md) | 简体中文

v0.2.18 收敛已合入主干的文本比较归一化：代码与文本比较新增两个默认开启的开关——忽略换行符差异、忽略编码差异。对比与合并算法、目录扫描口径、快照格式、导出内容与发布通道都没有改动。

## 本次变化

### 两个默认开启的比较开关

- **忽略换行符差异**：开关开启时，仅换行符不同的行不计入行级高亮、行内高亮与差异计数；关闭后恢复严格逐字节比较。状态栏的计数与结果里的差异计数读取同一份比较结果，不会出现两个数。
- **忽略编码差异**：开关开启时，文本相同、仅编码不同的两个文件不产生行级高亮与行内高亮，也不计入差异计数；关闭后同样逐字节比较。行级高亮、行内高亮与差异计数都遵循这条规则。

### 状态栏与探测原值

- **两侧原值**：状态栏始终分别显示左右两侧探测到的原始换行符与编码，即 `左侧换行符`、`左侧编码`、`右侧换行符` 与 `右侧编码`；切换任一比较开关都不会改写这些显示值。
- **探测随会话带入**：打开文件对时把两侧的探测事实带进会话，因此状态栏直接有值，不需要额外扫描。
- **不写回原文**：归一化只影响比较结果，不写回原文；导出内容、目录四态计数、快照格式与三向合并都不受影响。

## Windows 安装包与免安装 zip

此前的 CI 把 macOS 的 Developer ID 签名凭据（`CSC_LINK` / `CSC_KEY_PASSWORD`）注入到三平台矩阵的每个目标，Windows 构建因此带上了 Windows 不信任的签名，v0.2.17 的 `OpenCompare-Setup-0.2.17.exe` 被 `Get-AuthenticodeSignature` 判为 `UnknownError`。注入范围现已收窄到仅 macOS 目标，从本版起 Windows 安装包回到正常的未签名姿态（`NotSigned`）；SmartScreen 仍会提示未知发布者，等取得 Windows 代码签名证书后再补签。v0.2.17 的 Windows 安装包带的就是这份无效签名，建议直接使用 v0.2.18。

### Windows 免安装包

Windows 同时提供 NSIS 安装包与免安装 `.zip`，解压即用、无安装步骤。自动更新仍指向 NSIS 安装包，免安装 zip 只作为下载。

## macOS 签名与公证

macOS 包经 Developer ID 签名 + Apple 公证；签名凭据缺失时 CI fail-closed。本版把签名凭据的注入范围收窄到仅 macOS 目标，Windows 构建不再被误签；macOS 的 Developer ID 签名与 Apple 公证口径本身不变。

## 不做的事

- 除两个开关外不改对比与合并算法：四态语义、行级差异结果与三向合并行为保持原状。
- 不改目录扫描口径、快照格式、导出内容与发布通道。

## 风险与验证规模

本版改动集中在两个归一化开关、状态栏的原始换行符与编码显示，以及同一份差异计数：对比 / 合并算法、目录扫描与快照格式均未改动。真实落盘证据覆盖六个变体——UTF-8、UTF-8 BOM、UTF-16LE、GBK 搭配 LF 与 CRLF——千行组与 5 MiB 组都有覆盖。本文件不写任何性能或内存数字。

## 升级方式

建议从 v0.2.17 升级：下载 v0.2.18 对应平台的新安装包覆盖安装（macOS `.dmg` / `.zip`，Windows 安装包，Linux `.AppImage` / `.deb`）。Windows 可选 NSIS 安装包，或下载 `OpenCompare-0.2.18-win-x64.zip` 解压即用；自动更新仍只走 NSIS exe。本次不需要迁移数据，已有的会话与设置照常可用。签名与公证口径不变：macOS 包经 Developer ID 签名 + Apple 公证，凭据缺失时 fail-closed。
