## 4. 未执行的取证动作

以下动作按 blocked 分支要求全部未执行，未产生任何输出、路径、字节数或 SHA-256：

- 下载 dmg / zip / `latest-mac.yml` / `latest.yml` 到仓库外临时目录。
- `shasum -a 256` 计算 dmg 与 zip。
- `ditto -x -k` 解包 zip、`hdiutil attach -nobrowse -readonly` 挂载 dmg。
- 对两个 `OpenCompare.app` 运行 `codesign --verify --deep --strict --verbose=2`。
- 运行 `codesign -dv --verbose=4` 记录 Authority / TeamIdentifier / runtime。
- 运行 `xcrun stapler validate`。
- 运行 `spctl -a -vv --type execute`。
- 读取 `Contents/Info.plist` 的 `CFBundleIconFile`、`CFBundleShortVersionString` 与图标资源 SHA-256。
- 版本一致性核对（产物名 / `latest*.yml` / tag / `CFBundleShortVersionString`）与 `hdiutil detach`。
