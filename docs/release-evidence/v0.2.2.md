### 7.1 包内图标 vs 仓库品牌图标

```bash
shasum -a 256 build/icon.icns
```

原始输出：

```text
a099851e7c8888e244410a5490800e837920d337c2588fb9e70ce577c2fc0f8f  build/icon.icns
```

包内 `Contents/Resources/icon.icns` 与仓库 `build/icon.icns` 的 SHA-256 **完全一致**：`electron-builder` 把仓库里的品牌图标原样拷进包内，因此包内图标就是自制品牌图标，不是 Electron 默认图标。

> 口径说明：`prd.md` 的 `ac-evidence-v022-bundle-identity` 写作「该 icns SHA-256 与仓库 `build/icon.icns` 的值**不相同**」，与实测不符（`electron-builder` 直接拷贝该文件，必然相同）。本文件据实记录为「相同」，未做任何篡改；「非 Electron 默认图标」的判定在 CI 的打包后硬校验里完成（比对 `electron.icns` 时要求不相等），本机未安装 `node_modules/electron`，没有可对比的默认图标文件。
