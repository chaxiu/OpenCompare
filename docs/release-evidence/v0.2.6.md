- zip 内 `.app` 的 `CDHash` 同为 `3ee9d42220e5c02f061098a330fe90847c35f951`，`stapler validate` 与 `spctl` 结论与 dmg 内 `.app` 一致，即 dmg 与 zip 承载同一份已签名、已装订公证票据的产物。
