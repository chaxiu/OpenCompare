- 测量口径：`gh release view v0.2.15 --json body --jq .body | wc -m` 实测 4,937 个字符（含尾部换行）；`gh release view v0.2.15 --json body` 直接取值为 4,936，因为 gh 会去掉尾部换行。两者差 1 即换行符，结论不受该口径影响。
