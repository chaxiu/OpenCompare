status: partial

本文件记录 `v0.2.11` 的发布取证现状。事实来源仅限仓内 `docs/release-notes/v0.2.11.md`：该文件已载明本版两项面向用户的变化、对应实测数字与验证来源 run `trun_08764efa44c39426` / commit `2bcdc53e`，以及 CI 测试超时修复。tag、公开 Release、Release CI run、资产清单、签名与公证、L1 公开包复验这些发布期证据没有归档到本仓库，逐节标注为「证据目录缺失」；本文件不据版本号或 CI 结论推定发布形态。

## 1. 本版已载明的变化

| 变化 | 仓内 notes 已载明的事实 |
| --- | --- |
| 双栏 diff 侧边常驻竖向四态差异指示条 | 按行级 `same` / `added` / `removed` / `modified` 四态聚合，相同行不着色；内置样本、目录下钻、拖放与打开文件进入的双栏对比都带指示条；切到三向合并（三栏）时不显示；滚动任一栏时视口窗跟随移动 |
| 大行数双栏改为可视窗口渲染 | 双栏 diff 只渲染视口内的行与少量上下缓冲，不再为全部行创建行元素；滚动条总高仍按真实内容计算 |

### 2.3 CI 测试超时修复

- `src/renderer/src/components/DiffRuler.scale.test.tsx` 的 358,000 行「每个非 same 行都被同状态标记覆盖」同步遍历用例，此前走 vitest 默认 5000ms per-test 超时；CI attempt1 实测该用例耗时 6,816ms，撞上默认上限被判超时。
- 该用例现在带显式 `30_000` per-test 超时（第三参数），相对 CI 实测 6,816ms 约 4.4x 余量；全局 `testTimeout` / `hookTimeout` 未改，其它用例仍走默认 5000ms；358,000 行规模、用例数量与逐行覆盖断言全部保留。
- 同版本本机全量 `pnpm test` 为 27.42s / 69 files / 1104 passed；差异来自 runner 速度，不是产品逻辑回归。
