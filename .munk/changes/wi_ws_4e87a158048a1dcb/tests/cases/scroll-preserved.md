标题: 往返后左右目录面板滚动位置各自保持（含大目录长列表）
步骤: 准备左右目录各含 60+ 个文件的长列表（差异项分布在中部与底部），打开目录对比 → 左栏向下滚到中部并记下顶部可见行，右栏滚到接近底部并记下可见行 → 双击当前可见的差异文件下钻 → 点「返回上级目录视图」→ 对比两栏可见首行与滚动条位置 → 再下钻/返回一次复核
期望: 返回后左栏停在原中部偏移、右栏停在原接近底部偏移，两栏可见首行与滚动位置与下钻前一致——不跳回顶部、不跳到别处，两栏各自独立记忆；再次往返仍一致，滚动容器重建不导致位置丢失，过滤等其他状态同时保持。
