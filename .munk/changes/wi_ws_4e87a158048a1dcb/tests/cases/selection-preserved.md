covers: ac-selection-preserved
标题: 目录树行单击选中并高亮，往返与切标签后选中项与高亮保持
步骤: 打开真实目录对 → 单击左栏 `engine.ts` 行观察高亮与行语义 → 单击另一文件行确认单选切换 → 再点回 `engine.ts`，并单击一个目录行观察选中表现 → 选中 `engine.ts` 后双击它下钻 → 点「返回上级目录视图」→ 核对选中行与高亮 → 切到另一会话再切回，并再做一次下钻/返回
期望: 单击即选中：被选行有清晰可见的高亮（基于 `--color-accent-soft` 语义底色，非写死颜色），同一时刻只有一个相对路径处于选中（左/右栏同一相对路径行同步高亮，不出现多选），点展开/折叠按钮不会改变选中；往返后 `engine.ts` 仍为选中行且高亮可见；切换会话再回来后与再次往返后选中项与高亮仍保持，不会被清空。
