标题: 真实目录双击差异文件下钻到代码/CSV/JSON-YAML 文件级对比并携带两侧内容
步骤: 准备两个真实目录（含修改的 `src/core/engine.ts`、`data/report.csv`、`config/deploy.yaml`，以及左右独有文件），`pnpm dev` 冷启动 → 点「打开文件夹」依次选左、右目录建立目录对比会话 → 点「仅差异」→ 双击 `engine.ts`，观察工作区、会话标签与文件视图顶部来源条 → 点「返回上级目录视图」→ 双击 `report.csv` 观察表格 → 返回后双击 `deploy.yaml` 观察结构化视图
期望: 三次双击都立即切到对应文件级对比视图：代码/文本进双栏 Diff 并显示两侧真实文件内容（左/右独有文件对应侧为空），`.csv` 进 CSV 表格视图并按 `,` 解析出左右各自行数，`.yaml` 进结构化视图并按 YAML 解析呈现左右内容；每个下钻都生成单位文件命名的独立会话标签且目录对比标签仍在，文件视图顶部显示「来源目录对比：<目录会话标题>」；全程无「暂不支持下钻」误报、无解析或读取报错。
