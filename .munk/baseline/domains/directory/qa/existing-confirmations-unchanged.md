标题: 目录同步与模板归位的预览/确认/取消语义保持不变
步骤: 1) 打开两个真实目录建立目录对比会话；2) 工具栏「同步方向」选「左 → 右」、「同步模式」选「增量」，点「预览并同步」，核对弹窗标题、目标根、分组（待新增 / 待覆盖）、每项相对路径与字节数、合计项数/字节；3) 点「取消」，核对目标目录内容、目录树与状态栏统计；4) 再次「预览并同步」并按预览确认，核对目标侧写入与对比刷新；5) 点「模板归位」打开预览，核对模板 A 根 / 散乱树 B 根 / 输出根与已匹配 / 缺失 / 冲突 / B 未使用四组计数；6) 点「取消」，核对输出根
期望: 两个危险动作仍先弹出 `role="dialog"` 预览：同步弹窗标题为「{方向} · {模式}同步预览」并展示目标根与分组明细/字节汇总（镜像模式含待删除），模板归位弹窗标题为「模板归位映射预览」并展示 A/B/输出根与四组计数；确认前不写任何文件；取消后弹窗关闭、目标目录与输出根均无写入、目录树与统计保持不变；按预览确认同步后仍按预览项写入并刷新对比结果，既有确认语义未被后台保存/导出改道绕过或弱化。
