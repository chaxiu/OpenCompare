标题: 来源目录会话不可用时返回给出明确提示并落到可用目录视图，不崩溃不死路
步骤: 场景一：建立目录会话 A、B 并从 A 双击下钻，然后令来源目录会话 A 不可用（当前 UI 尚无会话关闭入口，关闭能力属 session-tabs-lifecycle 子项，故以脚本化内存 PlatformPort 的会话表移除 A 构造）→ 点「返回上级目录视图」→ 观察状态栏提示与落点、B 的目录树渲染；场景二：会话表只剩该下钻文件会话、无任何目录会话时点「返回上级目录视图」→ 观察提示与界面可用性
期望: 场景一：状态栏出现明确提示「来源目录会话已不可用，已返回可用的目录对比：<B 标题>」，激活 B 的目录对比视图并正常渲染左右树与状态栏会话标识，无白屏/无崩溃；场景二：状态栏给出「来源目录会话已不可用，当前也没有其他目录对比会话可返回」的明确提示，停留在文件视图仍可切标签或重新打开目录，不崩溃、不出现死路。
