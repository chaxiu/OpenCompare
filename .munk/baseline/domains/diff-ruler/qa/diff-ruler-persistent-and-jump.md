# diff-ruler-persistent-and-jump

covers: ac-ruler-persistent, ac-ruler-jump
标题: 双栏代码 Diff 常驻指示条，点选差异标记左右两栏对齐跳到同一差异块
步骤: 进入「代码对比」双栏 Diff（内置样本）→ 观察右侧窄条指示条是否存在；再从目录会话双击下钻一个文本文件对，观察同一指示条 → 点选任一差异标记 → 用顶栏「下一个 / 上一个差异块」在几个块之间来回 → 对已激活块的标记再次点选（中间先滚动离开）
期望: 两种入口都常驻指示条且不占分隔条位置（分隔条仍只有一条）；点选标记后左右两栏同时滚到该差异块首行（两栏滚动位置一致），顶栏「差异块 当前/总数」与状态徽标切到该块，块内行出现主色描边高亮；连续点选不同标记可连续上下跳转，对已激活标记再次点选仍回到该块首行；切到三向合并不显示指示条，切回 Diff 指示条恢复；覆写 / 重置 / 打开左或右文件后指示条仍在并在同一帧内按新 diff 重绘
