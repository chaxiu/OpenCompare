# diff-ruler-drilldown-roundtrip

covers: ac-drilldown-roundtrip
标题: 目录下钻文件对的指示条点选可对齐跳转，返回上级目录后状态原样且不重新读盘，重复下钻标记一致
步骤: 自动化：`pnpm test -- App.ruler` 中 drilldown 用例全绿 → 实机：打开一对真实目录 → 在目录视图里切到「仅差异」并折叠一个子目录、把树滚到中间 → 双击某个有差异的文本文件进入双栏 Diff → 点选指示条上的一个标记 → 点「返回上级目录视图」→ 再次双击同一个文件
期望: 下钻后页面上恰好一条指示条（不是两条、也不在分隔条位置）且至少有一个标记；点选标记后两栏同时滚到该差异块首行、两栏 `scrollTop` 相等、顶栏差异块计数与状态徽标同步、块内行出现主色描边；返回上级目录后指示条消失，目录树行标题、当前「仅差异」筛选、折叠状态与树的滚动位置都与下钻前一致，全程不新增文件读取 / 目录列举 / 摘要校验或哈希；再次下钻同一文件对，标记的状态与起止行序列与第一次逐项相同
