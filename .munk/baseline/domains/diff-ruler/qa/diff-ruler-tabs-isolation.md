# diff-ruler-tabs-isolation

covers: ac-tabs-switch-no-io, ac-tabs-ruler-isolation
标题: 3 个会话 tab 常驻时指示条各自隔离，来回切换零读盘且不出现扫描 / 摘要进度
步骤: 自动化：`pnpm test -- App.ruler` 全绿 → 实机：用「打开文件」开两对不同文件的对照（各进一个 tab），再用「打开文件夹」开一个目录会话（第 3 个 tab）→ 在 3 个 tab 之间来回切换两轮 → 每个 diff tab 切回后滚动并点选几个标记 → 切到目录 tab，再切回第一个 diff tab
期望: 每个双栏 diff tab 都有自己的指示条，两对文件的标记区间（状态 + 起止行）互不相同；来回切换后每个 tab 的标记区间与它首次显示时逐项一样，不串台、不残留上一个会话的标记；目录 tab 激活时页面上不存在任何指示条，切回 diff tab 指示条重新出现且区间不变；3 个 tab 各切两轮后没有任何文件读取、目录列举、摘要校验 / 哈希、路径解析动作，界面也不出现「正在扫描目录」「正在校验内容」一类进度提示；切换不丢各自的滚动位置、当前差异块与未保存编辑
