# diff-ruler-aggregation-and-regression

covers: ac-ruler-aggregation, ac-ruler-regression
标题: 指示条色带与行级四态逐行一致，空态 / 单侧 / 边界输入不越界且不新增 IO
步骤: 用同时含 added / removed / modified 的对照对进入双栏 Diff → 逐块点选核对标记颜色与正文行背景是否一一对应 → 打开左 / 右文件把两侧改成完全相同 → 把两侧都清空 → 再造单行文件、无尾换行文件与 CRLF 文件对 → 全程观察文件读取与响应
期望: 每个非 same 行都被同状态标记覆盖，same 不产生标记，同一差异块内混合状态按真实行级状态分别着色而不压成块级汇总；全相同时指示条常驻、无标记但视口窗仍随滚动移动；空 diff 时指示条常驻、无标记、工具栏 0/0 且上一 / 下一按钮禁用；仅左删只有 removed 标记、仅右增只有 added 标记且落在真实行位置；单行 / 无尾换行 / CRLF 不越界不偏移；滚动与点选不触发重新 diff、不新增文件读取或系统文件弹窗；行内字符高亮、覆写 / 重置 / 保存与分隔条拖拽行为保持原状；中英文界面均无未翻译残留
