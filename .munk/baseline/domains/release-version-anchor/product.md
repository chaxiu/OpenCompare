# Domain: release-version-anchor

发版前的**版本事实收敛**域：把一组已合入的变更固定成一个可发版版本锚点，只允许版本字面量、发布说明、截图 provenance 与视觉基线事实发生位移，产品行为、对比/合并语义与已公开事实零 diff。本域管 `package.json#version` 单一来源、双语 notes 结构、`CHANGELOG.md` 顶部段、workflow / `docs/release-process.md` 的默认 tag 字面量、已发布证据与台账（`docs/release-evidence/*.md` + `release-packaging.json#evidence.ledger`）、已发布指针（README 第 5 行）、README 截图 provenance 与 `docs/visual/v1/baseline-facts.json` 白名单；发布顺序归 `domains/release-publish-gate`，验证驱动与 15 项判定归 `domains/release-verify`，打包 / 签名 / 资产归 `domains/release`。当前锚点 `v0.2.24` 已公开发布（`releases/tag/v0.2.24`，tag 指向 `4191a8f`，非 draft）；其证据文件与台账由发布后收尾项补写。

## 范围

- **版本唯一来源**：`package.json#version` 是 tag 唯一来源（`v${version}`）；五处必须逐字相等——`package.json#version`、`CHANGELOG.md` 首个 `^## ` 标题、`docs/release-notes/v{version}.md` 一级标题内 tag、`release.yml` 的 `workflow_dispatch.inputs.tag.default`、`docs/release-process.md` 首个 `^default:\s*'([^']+)'$` 代码片段（`judgeVersionSources`）。收敛轮对 `package.json` 只允许改 `version` 一个字段。
- **已发布版本收尾（硬前置）**：升版前上一公开版本必须已有 `docs/release-evidence/v{prev}.md` 与同版本台账行（当前 `v0.2.23` 已闭合：证据文件 + `release-packaging.json#evidence.ledger` 行 + `verified` 状态）。缺失时旧段从「当前 tag」变历史段，`judgeReleaseHistory` 报 `evidence-missing`、`judgePublishedAnchor` 与已发布事实打架。`v0.2.24` 已公开但证据 / 台账尚缺：缺失期间 `judgeReleaseHistory` 按「pending 当前 tag」豁免；补写证据与台账属发布后收尾项，不在指针对齐项内。
- **改动白名单（按写路径可审计，不是固定文件数）**：收敛 commit 只允许落在——`package.json#version`、`docs/release-notes/v{version}.md` / `.zh-CN.md`、`CHANGELOG.md` 顶部段、`release.yml` / `docs/release-process.md` 的 default tag 字面量、确有新公开版本时的 `docs/release-evidence/v{prev}.md` 与台账行、`README.md` / `README.zh-CN.md` 第 5 行、`src/main/__fixtures__/release-announced-tag.json` 与 helper 的 `publishedTag` 合并、四张 README 截图 `docs/assets/opencompare-*.png` 与 `docs/screenshots.md` provenance、因版本号进入产物而重算的 `docs/visual/v1/baseline-facts.json#directoryHtml` / `refreshed`、以及同批 test-only 稳定性修补。禁止改动非测试的 `src/renderer/**`、`src/core/**`、`src/shared/**`、UI / i18n 产品文案、依赖、`electron-builder.yml`、门清单数值、`docs/release-evidence-ledger.json`、已公开 Release 与资产。
