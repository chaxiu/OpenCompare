标题: 真实 Electron 窗口走通「修改 → 免对话框原位写回 → 外部核对 → 导出合并/快照可复现」
步骤: 1) `pnpm dev` 在真实 Electron 窗口冷启动，不以 Web 预览通道代替；2) 在磁盘准备两个真实文本文件，点「打开文件」依次选中进入双栏 Diff；3) 选中差异块点「覆写到右」做出修改，确认右侧显示「已修改（未保存）」；4) 点「保存右文件」，确认**不出现系统保存对话框**、脏标记立即清除并出现「已写回 <右文件真实路径>」，右侧路径不变；5) 用 Finder / 终端外部读取右文件，核对内容等于修改后内容，并在应用内重新打开同一对文件再次核对；6) 进入三向合并（经「打开 base / ours / theirs」载入真实文件或演示场景），解决冲突后「导出合并文本」经系统保存对话框落盘；7) 打开两个真实目录建立目录对比，经系统保存对话框导出左侧快照为 `<目录名>.ocsnap.json`；8) 外部读取合并文本与快照，或把快照重新导入应用，核对内容与导出时一致；9) 全程观察是否出现无声下载、白屏、报错或断头路
期望: 真实 Electron 窗口（真实文件系统）全程走通：修改经「保存右文件」直接原位写回磁盘（无保存对话框、路径不变），外部读取确认磁盘内容为修改后内容，脏标记清除；合并文本与快照仍均经原生保存对话框落盘（不出现 Blob 无声下载），落盘文件外部可读、快照可再次导入且与导出时内容一致；无白屏、无控制台 error、无中断流程；本项不得据 Web 预览通道结果关点。
