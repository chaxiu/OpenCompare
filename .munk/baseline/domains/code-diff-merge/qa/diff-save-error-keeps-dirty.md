标题: 原位写回被平台拒绝时提示原因、脏标记保留且无系统保存对话框兜底
步骤: 1) 启动 Web 预览通道（`pnpm dev:web`）并加载演示样本，进入「代码 Diff & 3-Way Merge」场景的双栏 Diff；2) 点「覆写到右」，确认右侧显示「已修改（未保存）」；3) 记下右侧样本库路径（`/samples/...`）后点「保存右文件」；4) 观察是否弹出系统保存对话框、视图内提示的文案与语气、右侧脏标记、保存按钮与工作副本；5) 重新打开同一演示样本核对内容，并切到其他会话确认其状态
期望: 不出现系统保存对话框（不会给用户改投可写目标的兜底入口）；写入被平台以只读样本库拒绝，视图按既有报错语气明确提示（含「内置样本库」「只读」「不能写入」及具体样本路径），不出现成功提示；右侧仍保持「已修改（未保存）」、工具栏「未保存：右」不消失，保存按钮仍可再次点击重试；左右工作副本不被回滚、不被静默覆盖，其他会话与当前视图不受影响；无白屏、无未捕获异常。
