标题: 对内置样本库只读路径保存被拒绝并保持脏标记
步骤: 1) 启动 Web 预览通道（`pnpm dev:web`，该通道的 writeTextFile 直接按加载路径写入内存 FS，可确定性地命中只读样本路径）并加载演示样本，进入「代码 Diff & 3-Way Merge」场景的双栏 Diff；2) 点「覆写到右」，确认右侧显示「已修改（未保存）」；3) 记下右侧样本库路径（`/samples/...`）后点「保存右文件」；4) 观察视图内提示的文案与语气、右侧脏标记、保存按钮与工作副本；5) 重新打开同一演示样本核对内容。同一拒绝分支以平台单测（`web-platform.test.ts` / 只读样本拒绝用例）为辅证
期望: 「保存右文件」直接以 `/samples/...` 为写入目标（不弹保存对话框、不给改投可写目标的机会），写入被平台以只读样本库拒绝，视图按既有报错语气明确提示（含「内置样本库」「只读」「不能写入」及具体样本路径），不出现成功提示；右侧仍保持「已修改（未保存）」、工具栏「未保存：右」不消失；左右工作副本不被回滚、不被静默覆盖，重新打开样本内容保持原样；无白屏、无未捕获异常。
