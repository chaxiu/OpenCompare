covers: ac-save-in-place
标题: 已修改一侧按加载时的真实路径直接原位写回磁盘（不弹保存对话框）并清除脏标记
步骤: 1) `pnpm dev` 打开两个真实文本文件进入双栏 Diff，记录右文件的真实绝对路径与原始内容；2) 选中差异块点「覆写到右」，确认右侧显示「已修改（未保存）」且工具栏为「未保存：右」；3) 点「保存右文件」，观察是否出现系统保存对话框、视图内提示与右侧路径文案；4) 观察右侧脏标记、保存按钮与左侧状态；5) 退出应用或用 Finder / 终端外部读取右文件，再在本应用重新打开同一对文件核对
期望: 点「保存右文件」不弹出任何系统保存对话框，直接以右侧文件的真实绝对路径写入当前工作文本；视图提示「已写回 <右侧文件真实绝对路径>」，右侧「已修改（未保存）」与工具栏「未保存：右」立即消失、「保存右文件」转为禁用；面板/会话副标题中的右侧路径保持加载时的真实路径不变（不被替换为其他路径）；左侧无脏标记且工作内容不受影响；磁盘右文件内容与修改后工作文本逐字节一致（外部读取与再次打开均为修改后内容），左侧文件保持原样。
