covers: ac-export-roundtrip
标题: 导出的合并文本与快照可被外部读取或再次导入且内容可复现
步骤: 1) 准备三向合并场景（可打开真实 base / ours / theirs 文件），解决冲突后经保存对话框把合并文本导出到已知路径；2) 准备两个真实目录建立目录对比，经保存对话框把左侧快照导出到已知路径；3) 用 Finder / 终端 `cat` 等外部方式读取合并文本，与应用内预览逐行比对；4) 用外部方式读取 `.ocsnap.json`，核对 schema / name / entries / sha256 与内联 content；5) 回到应用的目录对比，点「导入左侧快照」选择刚导出的文件，核对左侧变为「快照」及条目；6) 让该快照与同一右侧目录重新对比，核对相同 / 新增 / 删除 / 修改计数；7) 从已挂载快照再次「导出左侧快照」，与首次导出文件逐字节比较
期望: 合并文本文件可被外部读取，内容与导出时预览逐行一致、不含冲突标记，也可作为真实文件再次被应用打开；`.ocsnap.json` 可被应用重新导入，左侧标记为「快照」，name / entries / 内联 content 与导出时一致；导入后的快照与同一右侧目录对比，状态计数与导出前该左侧目录的对比结果一致（无序列化丢失导致的差异）；从已挂载快照再次导出的文件与首次导出逐字节一致，证明产物可复现。
